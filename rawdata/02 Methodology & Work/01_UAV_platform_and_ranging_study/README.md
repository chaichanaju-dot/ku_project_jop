# การศึกษาแพลตฟอร์ม UAV และการวัดระยะ สำหรับงานตรวจรอยแตกคอนกรีตด้วย AI

**ไฟล์ส่งมอบ: [`UAV_platform_and_ranging_study.pdf`](UAV_platform_and_ranging_study.pdf)** — 46 หน้า A4 ภาษาไทย

## โจทย์ที่เอกสารนี้ตอบ

> "อยากทำโปรแกรมการบินให้โดรนบินใกล้วัตถุมากขึ้น เพื่อให้เห็นรอยแตกชัดขึ้นแล้วเอาภาพมารวมกัน
> และจะมีประโยชน์มากถ้ารู้ว่าโดรนอยู่ห่างจากวัตถุเป็นระยะเท่าไหร่"

**คำตอบสั้น** — เขียนโปรแกรมได้ผ่าน DJI SDK แต่แก้ปัญหาไม่ตรงจุด **การบินเข้าใกล้เป็นทางที่ผิด**
ทางที่ถูกคือ **ถอยออกแล้วซูม** และให้มาตราส่วนมาจากวัตถุอ้างอิงในภาพ ไม่ใช่จากเซนเซอร์วัดระยะ

## ข้อควรทราบก่อนนำไปอ้างในเล่ม

1. **ข้อมูลมาจากการค้นคว้าทางอินเทอร์เน็ต ไม่ได้มาจาก `rawdata/01 Literature Review/`** —
   ตามกฎข้อ 3 และ 4 ของ [`rule_of_tune.md`](../../../docs/rule_of_tune.md) ต้องตรวจสอบกับเอกสารต้นฉบับก่อนอ้าง
2. **ยังไม่ได้ทดสอบกับโดรนจริงและภาพถ่ายจริง** — ผลการทดสอบโค้ดเป็นการทดสอบกับภาพสังเคราะห์ที่รู้คำตอบจริง
3. รายการที่ยืนยันไม่ได้ถูกทำเครื่องหมาย "ยังไม่ยืนยัน" และรวบรวมไว้ในภาคผนวก ง. (106 ข้อ) — ไม่มีการเดาค่าให้
4. **อ่านบทที่ 11 ก่อนวางแผนงานจริง** — เป็นข้อจำกัดที่พบเมื่อนำทุกบทมาชนกัน และเปลี่ยนขอบเขตโปรเจกต์ ไม่ใช่แค่แก้ตัวเลข

## สามข้อที่ควรทำก่อนอย่างอื่น

1. ถ่ายภาพหนึ่งใบด้วยโดรนที่มีอยู่ แล้วรัน `exiftool -a -G1 IMG.JPG` ดูว่ามีระยะจาก laser rangefinder ติดมากับภาพไหม (5 นาที — ถ้ามีจะประหยัดงานได้มาก)
2. ถ่าย slanted-edge chart วัดความละเอียดเชิงแสงจริงของกล้อง — ถ้าเซนเซอร์เป็น quad-Bayer ตารางระยะบินทั้งหมดอาจต้องคูณ 0.5 (บทที่ 11.4)
3. วัดจำนวนพิกเซลขั้นต่ำที่รอยแตกต้องกินจึงจะวัดได้ ด้วยแผ่นรอยแตกอ้างอิง — แหล่งอ้างอิงให้ค่าต่างกัน 6 เท่า และระยะบินทุกตัวขึ้นกับตัวเลือกนี้ (บทที่ 11.5)
