ภาคผนวก ง. — คำถามที่ยังไม่มีคำตอบ

รายการนี้คือสิ่งที่ค้นแล้วยังยืนยันไม่ได้ในรอบนี้ — บันทึกไว้เพื่อไม่ให้ถูกลืม และเพื่อไม่ให้ใครเข้าใจผิดว่าเอกสารนี้ตอบครบทุกข้อ ทุกข้อระบุว่าต้องไปตรวจสอบที่ไหน

การวัดระยะ (16 ข้อ)

  • Update rate (Hz) ของ laser rangefinder บน Zenmuse H20/H20T/H20N, H30/H30T และ M30/M30T — DJI ไม่ระบุในหน้า spec สาธารณะ ต้องขอ OEM datasheet จาก DJI Enterprise support หรือดูคู่มือ PDF จากหน้า Downloads ของแต่ละ payload
  • Beam divergence ของ LRF บน Matrice 4 series และ Zenmuse H20 series — มีเฉพาะ H30 ที่ประกาศ spot size (50×450 mm @100 m) ส่วน H20 ให้แค่ reference aperture 18×18 mm ซึ่งไม่ใช่ divergence
  • สเปก LRF ที่แท้จริงของ Matrice 4D/4TD (measurement range, blind zone, accuracy formula, update rate) — หน้า enterprise.dji.com/matrice-4d-series/specs redirect เสียตอนค้น (ส.ค. 2026) ตัวเลข 1,800 m มาจากแหล่งขาย ไม่ใช่ DJI โดยตรง
  • อัตราอัปเดต (Hz) จริงของ ObstacleData และ PerceptionInfo listener ใน MSDK V5 — เอกสาร API ไม่ระบุเลย ต้องวัดเองด้วยการนับ callback บนเครื่องจริง (ใช้ PerceptionFragment.kt ใน SampleCode-V5)
  • Accuracy ของ vision obstacle sensing (binocular) ทุกรุ่น — DJI ไม่เคยประกาศ มีแต่ range/FOV ต้องทำ characterization เองเทียบกับ total station หรือ reference rangefinder
  • GitHub issue #368: targetPoint (0–1000) ของ laser API ไม่ทำให้ค่าระยะเปลี่ยน และ default เป็น (50,50) ไม่ใช่ (500,500) — ยังไม่มีคำตอบจาก DJI ต้องทดสอบเองว่าเลเซอร์เล็งตาม targetPoint ได้จริงหรือเล็งกลาง gimbal เสมอ
  • PSDK มี channel ให้ payload ป้อนค่าระยะกลับเข้า flight controller เพื่อทำ closed-loop standoff hold หรือไม่ (แบบ rangefinder ของ PX4/ArduPilot) — ต้องตรวจใน PSDK API reference หมวด data subscription + flight control ก่อนตัดสินใจซื้อฮาร์ดแวร์
  • Minimum focus distance ของกล้อง zoom บน Zenmuse H30/H30T ที่ระยะโฟกัสสุด (809.3 mm equiv) — ถ้าโฟกัสใกล้สุดไกลกว่า 10 m แผนถ่ายที่ 10–20 m ต้องปรับใหม่
  • ผลกระทบจริงของ quad-Bayer บนเซ็นเซอร์ 48 MP ขนาด 1/1.3" และ 1/1.5" ต่อ effective resolution — คาดว่าใกล้ 12 MP มากกว่า 48 MP ทำให้ GSD ใช้งานจริงแย่กว่าที่คำนวณราว 2 เท่า ต้องทดสอบด้วย resolution chart (USAF 1951 / Siemens star) ที่ 3, 5, 10 m
  • Minimum detection range ของ Zenmuse L1 และ Zenmuse L3 — หน้า spec โหลดไม่ครบ (L2 ระบุชัดที่ 3 m)
  • ยืนยันตัวเลข "RTK fix ล้มเหลวในระยะ 0–5 m จากสิ่งกีดขวาง และ re-fix 9–13 วินาที" ในเปเปอร์ต้นฉบับ (น่าจะอยู่ใน Drones 2026, 10(2), 91) ก่อนอ้างในเล่มวิทยานิพนธ์ — ปัจจุบันมาจากบทสรุปการค้น ไม่ใช่ full text
  • ยืนยันตัวเลข "error < 10% สำหรับรอยแตกบางกว่า 0.2 mm" ของงาน four-point laser (Automation in Construction 2026, Vol.182) — paywall ต้องเข้าถึงผ่านห้องสมุด ม.เกษตรฯ พร้อมดูว่าใช้ laser รุ่นอะไร ระยะบินเท่าไหร่ กล้องอะไร
  • Accuracy, resolution, beam divergence และน้ำหนักของ Benewake TF03 และ LightWare SF30/C, SF30/D, LW20/C — datasheet PDF อ่านอัตโนมัติไม่ได้ ต้องเปิดเอง
  • ราคาปัจจุบันของ DJI X-Port และ E-Port V2 ในไทย และ compatibility กับ M400 / M4 series — ต้องถามตัวแทนจำหน่าย DJI Enterprise
  • ข้อความข้อจำกัด obstacle sensing (texture, แสง, ผิวสะท้อน) ที่อ้างในรายงานนี้มาจากแหล่งสรุปที่สาม ไม่ใช่คู่มือ DJI ตัวจริง — ต้องตรวจซ้ำในคู่มือ PDF ของแต่ละรุ่นก่อนอ้างในเล่ม
  • Payload capacity ของ Matrice 4 series คือ 200 g — LightWare SF11/C 4 ตัว = 140 g บวก mounting/สายไฟ/คอมพิวเตอร์ อาจเกินพิกัด ต้องชั่งจริงหรือย้ายไปแพลตฟอร์ม M350/M400

marker / มาตราส่วน (10 ข้อ)

  • เกณฑ์ความกว้างรอยแตก (mm) และจำนวนระดับ condition rating ใน 'คู่มือการสำรวจและตรวจสอบสะพาน' ของกรมทางหลวง (382 หน้า จัดทำโดย ม.เกษตรศาสตร์) — โหลดไม่ได้ผ่านเว็บ ต้องดาวน์โหลด PDF เอง นี่คือช่องว่างใหญ่ที่สุดสำหรับบริบทไทย และจำเป็นต่อการ map ค่า mm ที่วัดได้ -> T-BHI
  • DJI ระบุ FOV ของ Matrice 4T แค่ '82 องศา' โดยไม่บอกว่าเป็น DFOV หรือ HFOV — ตาราง GSD ใน §3.4 คำนวณโดยสมมติเป็น DFOV ถ้าเป็น HFOV ค่าจะผิด ~25% วิธีตรวจ: ถ่ายไม้บรรทัดที่ระยะวัดจริง 2.00 m แล้วนับ pixel
  • Matrice 4 Series รองรับ Waypoint 3.0 ผ่าน Mobile SDK v5 หรือไม่ — เอกสาร DJI ที่ค้นเจอระบุรองรับเฉพาะ Matrice 30 Series / Mavic 3 Enterprise Series / Matrice 3D-3TD ถ้า M4 ยังไม่รองรับ ต้องพิจารณา Mavic 3E แทนสำหรับงานเขียนโปรแกรมบินเอง
  • รายละเอียดตัวเลขของ Germanese et al. 2018 (J. Imaging 4(8) 99) — ขนาด marker เป็น mm, รุ่น UAV, ระยะบิน, และ error ที่รายงาน — MDPI คืน HTTP 403 ตอน fetch ต้องโหลด PDF open-access เอง
  • ตัวเลข error เป็น % ของ Yoon et al. 'Feasibility Study for the Fine Crack Width Estimation of Concrete Structures Based on Fiducial Markers' (IEEE 9583237) — paywall ต้องเข้าผ่าน IEEE Xplore ของ ม.เกษตร งานนี้สำคัญเพราะสรุปว่า 'จำนวน pixel สำคัญกว่า GSD'
  • ตัวเลขเปรียบเทียบ ChArUco vs checkerboard (repeatability +/-0.03 mm vs +/-0.08 mm, ใช้ภาพน้อยกว่า 50%) มาจาก blog ของผู้ขายกระดาน calibration ไม่ใช่ peer-reviewed — อย่าอ้างในเล่มจบโดยไม่ทดลองเอง
  • ตัวเลขจาก arXiv:2509.17345 (marker 100mm -> detect ได้ 3.5 m ฯลฯ) สกัดจาก PDF 9MB ด้วยโมเดลเล็ก และ abstract ไม่ยืนยัน — ต้องเปิด PDF อ่านตารางจริงก่อนอ้าง
  • lens distortion ที่ขอบภาพของ Matrice 4T (ประมาณไว้ 2-5%) ไม่มีแหล่งอ้างอิงเฉพาะรุ่น — ต้อง calibrate เองแล้วคำนวณ r_distorted/r ที่ขอบภาพจากค่า k1/k2
  • รายละเอียด four-point laser metric calibration (Automation in Construction S0926580526000154) — ScienceDirect คืน 403 ยังไม่ทราบความแม่นที่รายงาน ทั้งที่เป็นทางเลือกโดยตรงของ marker เมื่อติด marker ไม่ได้
  • overlap ที่เหมาะสมสำหรับ stitching ระยะใกล้บนผิวคอนกรีต (ผมใช้ค่าทั่วไป 80% forward / 60% side) ยังไม่มีแหล่งอ้างอิงเฉพาะงาน crack inspection — งบ WebSearch หมดก่อนค้นได้

pipeline (12 ข้อ)

  • Effective resolution จริงของโหมด 48 MP บนเซนเซอร์ quad-Bayer ของ DJI ยังไม่ยืนยัน — ต้องวัดเองด้วย Siemens star / USAF 1951 target ใน Phase 0 ตัวเลข GSD ทั้งหมดในรายงานนี้เป็น nominal ถ้า effective ต่ำกว่า nominal 1.4x ต้องคูณระยะบิน D ด้วย 1/1.4
  • Actual focal length ของ DJI Mini 4 Pro (6.72 mm) และ Mavic 4 Pro ทุกเลนส์ ยังไม่ยืนยัน — DJI ไม่ประกาศในหน้า specs (ตรวจสอบแล้ว) ตัวเลข 6.72 mm มาจากฟอรัม/รีวิว จึงใช้ฟอร์ม FOV แทนในรายงานนี้ ถ้าต้องการยืนยันให้อ่านจาก EXIF ของภาพจริง (FocalLength tag)
  • ขนาดเซนเซอร์เป็น mm ของฟอร์แมต 1/1.3" และ 1/1.5" ยังไม่ยืนยัน — แหล่งอ้างอิงให้ค่าขัดกัน (9.6x7.2 vs 9.8x7.3 mm) ต้องดู datasheet ของเซนเซอร์รุ่นจริง (น่าจะเป็น Sony IMX ตระกูลหนึ่ง) หรือคำนวณย้อนจาก EXIF FocalLengthIn35mmFilm
  • DJI Matrice 4E/4T ไม่ประกาศ FOV ของกล้อง wide ในหน้า specs ที่ดึงมา — ต้องเปิดหน้า specs เต็มหรือคู่มือผู้ใช้เพื่อคำนวณ GSD ของรุ่นนี้
  • กฎ 'รอยแตกเล็กสุด = 3 x GSD' ยังไม่ยืนยันแหล่งปฐมภูมิ — พบใน secondary source ต้องหา primary reference (น่าจะเป็นงาน photogrammetry detectability หรือ Nyquist-based argument) ก่อนอ้างในวิทยานิพนธ์
  • ตาราง 4.9 ของ T-BHI (ค่าน้ำหนัก W_e ของแต่ละ element และการแบ่ง Primary/Secondary) ยังไม่ได้ดึงมาครบในรอบนี้ — ต้องเปิดหน้า 51-53 ของ PDF เพื่อได้ตารางเต็มก่อนเขียนโค้ดคำนวณ T-BHI
