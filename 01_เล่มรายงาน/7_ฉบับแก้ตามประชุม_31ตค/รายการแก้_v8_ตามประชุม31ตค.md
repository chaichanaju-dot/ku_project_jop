## แก้เพิ่ม 2 พ.ย. 2569 — LLM → VLM (มะขามสั่ง บันทึกทับไฟล์เดิม)

- ข้อความ "LLM" ทุกที่ → "VLM" และคำไทย "แบบจำลองภาษาขนาดใหญ่ (ที่รับภาพได้)" → "แบบจำลองภาษาภาพ" ให้ตรงกับตัวย่อ
- ชื่อเรื่อง: ไทย "…ด้วยแบบจำลองภาษาภาพ" · อังกฤษ "Development of an Automated Bridge Condition Assessment from UAV Imagery Using a Vision-Language Model" (เดิม "Using Multimodal LLM")
- **ตรวจกับถอดเสียงประชุมแล้ว:** อาจารย์อนุญาตให้ใช้ VLM เอง — 00:29:29 "multimodal large language model ไม่เป็นไร เอาเป็น vision language model ก็ได้ VLM ก็ได้" และ 01:49:56 "เขียน Qwen ก็เปลี่ยนเป็น LLM VLM แล้วแต่" · ชื่อเรื่องใช้รูปเอกพจน์ตามคำอาจารย์ · คอมเมนต์ชื่อเรื่องในเล่มแก้จาก "คำเชื่อมยังไม่แน่ใจ" เป็นเวลาในคลิปที่ยืนยันแล้ว
- 1.2 วัตถุประสงค์รอง: "(large language model: LLM) ที่รับภาพได้" → "(vision-language model: VLM)" — เป็นข้อความเดิมของ v7 จึงแก้แบบ track (ลบ+เพิ่ม) · 1.3 ข้อ (7) "จึงเลือกแบบจำลองภาษาขนาดใหญ่ที่รับภาพได้" → "แบบจำลองภาษาภาพ" แบบ track เช่นกัน
- 2.3.4 ตัดประโยค "หรือแบบจำลองภาษาขนาดใหญ่ที่รับภาพได้ (multimodal LLM)" และ "เล่มนี้ใช้คำว่า LLM ที่รับภาพได้ และ VLM ในความหมายเดียวกัน" (ไม่จำเป็นแล้ว)
- รูป 3.1 (กล่อง 3.2.3) และรูป 3.3 (กล่องซ้ายบน) วาดใหม่เป็น "VLM (ปรับแต่ง)"
- คอมเมนต์ 2 อันที่พูดถึง LLM แก้เป็น VLM
- **ไม่แก้:** ชื่อบทความในเอกสารอ้างอิง Dettmers et al. (2023) "…quantized LLMs" และ Hu et al. (2021) "…large language models" เพราะเป็นชื่อเปเปอร์จริง
