# ku_project_jop

โครงงานปริญญาตรี (KU, อ้างอิงรายวิชา 203499) เรื่อง **การตรวจสอบสภาพโครงสร้างสะพาน/เสาด้วย AI** ต่อยอดจากงานวิจัยที่ได้รับทุน วช. (ปีงบ 2568) — สังเคราะห์เกณฑ์การตรวจสอบสะพานที่มีอยู่ (มาตรฐานไทย BMMS, มาตรฐานสหรัฐฯ NBI/AASHTO) เข้ากับเกณฑ์ประเมิน T-BHI (Thailand Bridge Health Index) และแนวทาง deep learning / MLLM (วิเคราะห์ภาพจาก UAV → ตรวจจับ/จำแนกความเสียหาย → ให้คะแนนสภาพ) เพื่ออุดช่องว่างของการตรวจสอบด้วยคนแบบ manual ในปัจจุบัน

> **หมายเหตุ:** คำอธิบายข้างบนเป็นข้อมูลที่ Claude อนุมานจากชื่อโฟลเดอร์/ไฟล์ใน `rawdata/01 Literature Review/` เท่านั้น — ผู้ใช้ควรแก้ไขให้ตรงกับชื่อโครงงานจริง อาจารย์ที่ปรึกษา สมาชิกทีม และ timeline ที่แท้จริง

## สถานะปัจจุบัน

- ✅ **Literature Review** — รวบรวมแหล่งอ้างอิงแล้ว (เกณฑ์ตรวจสอบ, มาตรฐาน, งาน AI/deep learning ที่เกี่ยวข้อง, งานวิเคราะห์ช่องว่าง+วิธีการ)
- ⬜ **Methodology & Work** — ยังไม่เริ่ม
- ⬜ **Reports** — ยังไม่เริ่ม

## สำหรับ Claude / AI session

**`CLAUDE.md` ย้ายไปอยู่ที่ `docs/CLAUDE.md` ไม่ใช่ root แล้ว จึงไม่ auto-load** — ต้องบอก Claude ให้อ่านเองตอนเริ่ม session ใหม่ทุกครั้ง เช่น "อ่าน docs/CLAUDE.md ก่อน"

ก่อนแก้ไข/ลบ/ย้ายไฟล์ใดๆ ใน `rawdata/` ต้องอ่าน [docs/rule_of_tune.md](docs/rule_of_tune.md) ก่อนเสมอ — ไฟล์เหล่านั้นเป็นแหล่งอ้างอิงต้นฉบับของงานวิจัย ลบ/แก้ผิดอาจหาแทนไม่ได้

## หมายเหตุเรื่อง repo

- `rawdata/` มีขนาด ~121MB (PDF อ้างอิง) ถูก commit เข้า git ไปแล้วตั้งแต่ก่อนมี `.gitignore`
- ยังไม่มี CI/`.github/workflows/` เพราะยังไม่มีโค้ดที่ต้อง build/test (เป็นช่วง literature review/เขียนรายงาน) — ถ้า `02 Methodology & Work/` เริ่มมีโค้ด pipeline จริง (เช่น เทรน/ประเมินโมเดล) ค่อยพิจารณาเพิ่ม
