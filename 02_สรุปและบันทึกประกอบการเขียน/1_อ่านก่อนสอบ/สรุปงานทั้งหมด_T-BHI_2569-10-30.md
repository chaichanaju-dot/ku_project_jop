## ส่วนที่ 0 — ภาพรวมแบบเล่าเป็นเรื่อง (อ่านก่อน)

**ปัญหา:** สะพานต้องมีคนไปตรวจสภาพเป็นระยะ การตรวจแบบเดิมต้องมีทีมงาน ต้องใช้เครื่องจักรยกคนขึ้นที่สูง บางครั้งต้องปิดถนน อันตรายและกระทบการจราจร

**ไอเดีย:** ให้โดรนถ่ายภาพสะพาน แล้วให้คอมพิวเตอร์ช่วยดูว่า "ตรงไหนคือส่วนไหนของสะพาน" และ "ตรงไหนเสียหายแบบไหน" แล้วคำนวณเป็นคะแนนสุขภาพสะพาน 0–100 ตามเกณฑ์ที่กรมทางหลวงใช้อยู่จริง

**ส่วนที่งานนี้เพิ่ม (จุดขาย):** งานวิจัยส่วนใหญ่หยุดแค่ "AI หารอยร้าวเจอแล้ว" แต่ไม่มีใครต่อไปถึง "ได้ระดับสภาพตามมาตรฐาน และคะแนนรวมของสะพาน" งานนี้ต่อให้ครบ และใช้เลเซอร์ช่วยให้รู้ขนาดรอยเป็นมิลลิเมตรจริง ไม่ใช่แค่จำนวนพิกเซล

## ส่วนที่ 1 — ศัพท์พื้นฐานที่ต้องรู้ (อธิบายแบบคนไม่เคยเรียน)

| คำ | แปลง่ายๆ |
|---|---|
| **UAV / โดรน** | อากาศยานไร้คนขับ ในงานนี้ใช้ DJI Matrice 4E (ภาพชุดใหม่) และภาพชุดเดิมถ่ายด้วย DJI Mavic 3 Enterprise |
| **คอนกรีตเสริมเหล็ก (RC)** | คอนกรีตที่ใส่เหล็กเส้นไว้ข้างใน เหล็กรับแรงดึง คอนกรีตรับแรงอัด |
| **คอนกรีตอัดแรง (PC)** | คอนกรีตที่ดึงลวดเหล็กให้ตึงไว้ก่อนแล้วค่อยหล่อ ทำให้รอยร้าวเปิดยาก รอยร้าวที่เกิดจึง "ละเอียดมาก" (หลักร้อยของ มม.) |
| **คานตัวไอ (I-girder)** | คานที่หน้าตัดรูปตัว I วางพาดระหว่างตอม่อ รับพื้นสะพานด้านบน สะพานกรณีศึกษาใช้ชนิดนี้ |
| **ตอม่อ / หัวเสา (คานรัดหัวเสา)** | ตอม่อคือเสาของสะพานที่ส่งน้ำหนักลงฐานราก คานรัดหัวเสาคือคานที่พาดอยู่บนหัวเสา รับคานตัวไอ งานนี้เรียกสั้นว่า "หัวเสา" |
| **BMMS** | ระบบบริหารงานบำรุงรักษาสะพานของกรมทางหลวง มีคู่มือสำรวจ/ตรวจสอบสะพาน เป็นแหล่งเกณฑ์ระดับสภาพหลักของงานนี้ (รายงานอ้างว่าเป็นเอกสารที่หน่วยงานใช้จริง ไม่ใช่งานวิชาการ) |
| **ระดับสภาพ 0–5** | คะแนนสภาพของชิ้นส่วน 5 = ดีมาก … 0 = วิบัติ (ตารางที่ 2.3) |
| **การตรวจจับ (detection) กับ การแบ่งส่วน (segmentation)** | detection ได้ "กรอบสี่เหลี่ยม" ล้อมวัตถุ ส่วน segmentation ระบายสีตามรูปร่างจริงทีละพิกเซล งานนี้ต้องใช้อย่างหลัง เพราะต้องนับ **พื้นที่** และกรอบสี่เหลี่ยมกินพื้นที่ว่างรอบรอยร้าวที่คดโค้ง |
| **mask** | ผลลัพธ์ของการแบ่งส่วน คือ "แผ่นสีทาบ" บอกว่าพิกเซลไหนเป็นวัตถุนั้น |
| **YOLO / YOLO26-seg** | โมเดลตรวจจับวัตถุที่ดูภาพรอบเดียวแล้วตอบเลย (รุ่น 26-seg วาด mask ได้ด้วย) ในงานนี้ใช้แบ่งชิ้นส่วนสะพาน |
| **SAM / SAM 3** | โมเดลที่ "ตัดวัตถุออกจากภาพ" ตามคำสั่ง (พรอมต์) เช่น กรอบหรือจุด แล้วคืน mask SAM 3 รับคำสั่งเป็นกรอบ/จุด/mask หรือเป็นแนวคิด (วลีนาม) ก็ได้ |
| **พรอมต์ (prompt)** | สิ่งที่ผู้ใช้ป้อนให้โมเดลเพื่อบอกว่าให้หาอะไร |
| **VLM / Qwen** | VLM = โมเดลภาษาภาพ รับภาพ+ข้อความ ตอบเป็นข้อความ Qwen เป็นตระกูลที่ระบุตำแหน่งวัตถุด้วยกรอบหรือจุดได้ รุ่นที่เลือกคือ Qwen3.6-35B-A3B |
| **fine-tune / LoRA** | fine-tune = ปรับโมเดลสำเร็จรูปให้เก่งงานเฉพาะด้วยข้อมูลของเรา LoRA = วิธีปรับที่ฝึกเฉพาะ "ส่วนเสริมเล็กๆ" ไม่แตะน้ำหนักเดิม ประหยัดทรัพยากร ปรับพารามิเตอร์แค่ราว 0.1–1.3% |
| **precision / recall** | precision = ที่ AI บอกว่าเจอ เจอจริงกี่ส่วน · recall = ที่มีอยู่จริง AI เจอได้กี่ส่วน |
| **IoU / Dice** | วัดว่า mask ของ AI ซ้อนทับกับ mask เฉลยมากแค่ไหน IoU = พื้นที่ซ้อนทับ ÷ พื้นที่รวม · Dice = 2×ซ้อนทับ ÷ ผลรวมพื้นที่ทั้งสอง |
| **mAP50 / mAP50–95** | ค่าเฉลี่ยความแม่นข้ามประเภท mAP50 นับว่า "ถูก" เมื่อ IoU ≥ 0.5, mAP50–95 เฉลี่ยที่เกณฑ์ 0.5 ถึง 0.95 |
| **GSD** | ขนาดจริงต่อ 1 พิกเซลบนผิว (มม./พิกเซล) คำนวณจากระยะกล้อง–ผิว ซึ่งในงานนี้ **ไม่ใช้** เพราะระยะนั้นรู้ไม่แม่น |
| **homography** | การแปลงเรขาคณิตที่ "ดัดภาพเอียงให้ตรง" จับคู่สี่จุดในภาพกับสี่จุดจริง งานนี้ใช้แก้ผลจากการถ่ายเฉียง |
| **crack scale** | แถบ/เกจที่มีความกว้างรอยร้าวมาตรฐานหลายขนาด วางข้างรอยเพื่อใช้เป็นเฉลยตอนทดสอบการวัด |
| **EHI** | ดัชนีสุขภาพรายชิ้นส่วน (element health index) 0–100 |
| **T-BHI** | ดัชนีสุขภาพสะพานไทย (Thai Bridge Health Index) 0–100 ทั้งสะพาน |
| **Tier 1** | การคัดกรองขั้นแรก ก่อนส่งวิศวกรตรวจละเอียด |

## ส่วนที่ 2 — บทที่ 1 บทนำ (อธิบายทีละหัวข้อ)

### 1.1 ความเป็นมา (ปัญหา 4 ข้อ ที่เล่มชี้)

1. **การตรวจแบบเดิมช้าและเสี่ยง** กรมทางหลวงตรวจตาม BMMS: ตรวจปกติทุก 1–2 ปี และตรวจหลักทุก 4–6 ปี ต้องใช้ทีม เครื่องยกคน และบางครั้งปิดถนน (Karim et al., 2021)
2. **งานวิจัยหยุดกลางทาง** โดรน + deep learning หารอยเสียหายเจอได้ แต่ส่วนใหญ่ไม่ไปถึง "ระดับสภาพมาตรฐาน" (Çelik et al., 2025) และงานที่ใช้ VLM กับสะพาน 13 งาน ไม่มีงานใดเชื่อมกับระดับสภาพ (Çelik et al., 2026)
3. **เกณฑ์เป็นมิลลิเมตร แต่ภาพเป็นพิกเซล** เกณฑ์ BMMS ผูกกับขนาดจริง เช่น ความกว้างรอยร้าวเป็น มม. แต่ภาพไม่บอกระยะกล้องถึงผิว ภาพที่ถ่ายห่างกันมีสเกลต่างกัน **จึงบวกพิกเซลข้ามภาพไม่ได้**
4. **ข้อมูลเดิมไม่พอ** สะพานกรณีศึกษา (สะพานเฉลิมพระเกียรติ 72 พรรษา จ.ฉะเชิงเทรา เป็น PC คานตัวไอ) เคยถูกบินเก็บภาพมากกว่า 1,000 ภาพในโครงการก่อนหน้า ซึ่งตรวจด้วยกรอบและให้ผู้ตรวจยืนยันผล รายงานเดิมระบุเองว่ากรอบละเอียดไม่พอจะคำนวณพื้นที่ความเสียหาย (ศุภศิษฏ์ ศรีวรานันท์ และคณะ, 2569ก)

**ข้อเสนอ:** ระบบคัดกรองขั้นแรก: โดรนถ่าย → AI แบ่งส่วนชิ้นส่วนและความเสียหาย → เลเซอร์ 4 จุดวัดขนาดจริงด้วยการนับ pixel → แปลงเป็นระดับ EHI และ T-BHI ตามเกณฑ์กรมทางหลวง → ระบุค่าความมั่นใจที่จุดไม่แน่ใจ

### 1.2 วัตถุประสงค์ 5 ข้อ (แปลเป็นภาษาง่าย)

| ข้อ | ต้องทำอะไร | วัดผลอย่างไร |
|---|---|---|
| 1 | ทำแบบจำลองแบ่งส่วน **ชิ้นส่วน 5 ประเภท** (เสา คาน หัวเสา พื้น ราว) จากภาพ UAV | รายงานผลแยกรายประเภท |
| 2 | ทำลำดับ **Qwen (fine-tune) ระบุตำแหน่ง+ชนิดความเสียหาย 6 ประเภท → SAM 3 (fine-tune) วาด mask** และทดสอบว่ากรอบของ Qwen ใกล้เคียงหรือไม่ต่ำกว่า YOLO26 แบบกรอบ | เทียบกรอบ Qwen กับ YOLO26 |
| 3 | ออกแบบ **ชุดเลเซอร์ 4 จุดบนโดรน** และหาช่วงเงื่อนไข (ระยะ มุม แสง) ที่วัดสเกล/ความกว้างรอยเชื่อถือได้ พร้อมค่าคลาดเคลื่อน | ใช้ crack scale เป็นค่าอ้างอิง |
| 4 | เขียนโปรแกรมแปลงผลภาพ → **ระดับ 0–5, EHI, T-BHI, สถานะ, ค่าความมั่นใจ** ที่ตรวจย้อนได้ทุกขั้น | ตรวจย้อนได้ตามเกณฑ์กรมทางหลวง |
| 5 | เปรียบเทียบผลระบบกับการประเมินของวิศวกรบนสะพานกรณีศึกษา | สถานะตรงกับวิศวกรไหม และพลาดไปทางอันตรายหรือไม่ |

**ไม่ตั้งเกณฑ์ผ่าน/ไม่ผ่านเชิงตัวเลขล่วงหน้า** เพราะยังไม่มีค่าฐานของงานแบบนี้บนภาพโดรนสะพานไทย จะรายงานค่าที่วัดได้จริง

### 1.3 ขอบเขต 6 ข้อ (สิ่งที่ทำ และสิ่งที่ไม่ทำ)

1. **สะพาน:** แห่งเดียว คือสะพานเฉลิมพระเกียรติ 72 พรรษา (รหัส 144210087) ชนิด PC คานตัวไอ → สรุปให้เป็นกรณีทั่วไปไม่ได้
2. **ข้อมูล:** ชุดเดิม (Mavic 3 Enterprise) ใช้ฝึกและทดสอบ + ชุดใหม่ (Matrice 4E พร้อมเลเซอร์ 4 จุดและ crack scale) ใช้ทดสอบการวัดขนาดและทดสอบแบบจำลองอย่างอิสระ
3. **ชิ้นส่วน/ความเสียหาย:** ชิ้นส่วน 5 ประเภท · ความเสียหาย 6 ประเภท = Crack, Efflorescence, Rust_Stain, Spalling, Exposed_Rebar, Honeycomb · ชิ้นส่วนที่โดรนมองไม่เห็นหรือไม่แบ่งส่วน (ฐานราก แผ่นรองรับ รอยต่อ ผิวทาง) **ไม่อยู่ใน T-BHI**
4. **เกณฑ์:** ระดับ 0–5 + เกณฑ์รอยร้าวของกรมทางหลวง · สมการดัชนีตามรูปของ AASHTO · น้ำหนักของ Pellegrino et al. (2011) · ส่วนที่มาตรฐานไม่กำหนด (ช่วงคะแนนสถานะ กฎบังคับสถานะ) เป็น **ข้อกำหนดของผู้จัดทำ**
5. **ลักษณะระบบ:** คัดกรอง Tier 1 ไม่ตัดสินขั้นสุดท้าย ไม่ประเมินความสามารถรับน้ำหนัก ไม่ใช้การทดสอบแบบไม่ทำลาย ทำงานอัตโนมัติ ไม่มีขั้นให้ผู้ใช้แก้ผล
6. **ข้อจำกัดของภาพ:** ความลึกกะเทาะและการเสียหน้าตัดของเหล็กวัดจากภาพไม่ได้ ต้องใช้ตัวบ่งชี้ทางอ้อม · รอยร้าวของ PC ละเอียดเกินกว่าภาพโดรนแยกได้ จึงให้ค่าความมั่นใจต่ำ

### 1.4 ประโยชน์ที่คาดว่าจะได้รับ 5 ข้อ

เครื่องมือคัดกรองสะพานจากภาพ · ชุดป้ายโพลิกอนชิ้นส่วน 5 + ความเสียหาย 6 ประเภทบนภาพโดรนสะพานไทย พร้อมกติกาติดป้าย · วิธีวัดขนาดจริงด้วยเลเซอร์ 4 จุดและช่วงเงื่อนไขที่เชื่อถือได้ · คำตอบว่า VLM ที่ fine-tune แล้วให้กรอบความเสียหายคอนกรีตแม่นพอหรือไม่ (ยังไม่พบรายงานก่อนหน้า) · โปรแกรมคำนวณ EHI/T-BHI ตรวจย้อนได้ สอดคล้องวิธีของโครงการแพลตฟอร์มดิจิทัลแฝด (ศุภศิษฏ์ ศรีวรานันท์ และคณะ, 2569ข)

## ส่วนที่ 3 — บทที่ 2 ทฤษฎีและวรรณกรรม (เรียงตามเล่ม)

บท 2 มีหน้าที่ "รองรับบท 3" คือทุกวิธีที่ใช้ในบท 3 ต้องมีทฤษฎีหรืองานวิจัยรองรับในบทนี้ จึงเรียงตามขั้นตอน: สะพาน/ความเสียหาย → เกณฑ์/ดัชนี → deep learning → ถ่ายภาพ → ขนาดจริง → งานเกี่ยวข้อง/ช่องว่าง

### 2.1 ประเภท องค์ประกอบ และความเสียหายของสะพานคอนกรีต

**2.1.1 RC และ PC.** BMMS ครอบคลุมสะพานคอนกรีตและสะพานโครงสร้างประกอบ ไม่รวมสะพานขึง จัดทำจากความเสียหายที่ **มองเห็นด้วยสายตา** BMMS มีเกณฑ์ความเสียหายของ PC แยกจาก RC เฉพาะตารางของ พื้นสะพาน คานตามยาว คานรัดหัวเสา เสาเข็ม (ตาราง 4-3, 4-5, 4-9, 4-19) ส่วนค้ำยันคาน ค้ำยันตอม่อ เสาตอม่อ กำแพงตอม่อ ฐานราก มีเกณฑ์ RC อย่างเดียว · รายงานสำรวจสะพานกรณีศึกษาบันทึกความเสียหาย: คราบสนิมที่คานขวาง คอนกรีตกะเทาะ รอยร้าว (บางช่วงกะเทาะ/คราบเกลือรุนแรงที่จุดต่อ เหล็กเสริมโผล่เป็นสนิม รอยร้าวแนวดิ่งที่รอยต่อคาน) · BMMS ระบุว่า hairline คือรอยที่วัดด้วยอุปกรณ์ธรรมดาไม่ได้ และรอย PC ต้องวัดด้วย crack gauge

**2.1.2 องค์ประกอบสะพาน.** BMMS แบ่ง 3 กลุ่ม: ส่วนบน (พื้นสะพาน คานตามยาว ค้ำยันคาน) · ส่วนล่าง (คานรัดหัวเสา ค้ำยันตอม่อ เสาตอม่อ กำแพงตอม่อ ฐานราก เสาเข็ม) · ส่วนประกอบรอง (ราว ผิวทาง รอยต่อ ระบบระบายน้ำ) การจับเข้ากับ 5 ประเภทของงานนี้ (ตารางที่ 2.1):

| องค์ประกอบ BMMS | ประเภทของงานนี้ |
|---|---|
| พื้นสะพาน | **พื้น** |
| คานตามยาว (หลักเป็น PC คานตัวไอ), ค้ำยันคาน/คานขวาง | **คาน** (คานทุกชนิดรวมประเภทเดียว) |
| คานรัดหัวเสา | **หัวเสา** |
| เสาตอม่อ, กำแพงตอม่อ | **เสา** (รวมตอม่อ) |
| ราวสะพาน/แผงกั้นจราจร | **ราว** |
| ค้ำยันตอม่อ, ฐานราก, เสาเข็ม, ผิวทาง, รอยต่อ, ระบบระบายน้ำ | **ไม่อยู่ใน 5 ประเภท** โดรนมองไม่เห็น/ไม่แบ่งส่วน จึงไม่เข้า T-BHI |

**2.1.3 ความเสียหายตามนิยาม BMMS (ข้อ 4.1.1).** ตารางที่ 2.2 จับ 6 ประเภทของงานนี้กับนิยาม:

| ประเภท | ใจความ + ข้อสังเกตเรื่องภาพ |
|---|---|
| Crack รอยร้าว | hairline = วัดด้วยอุปกรณ์ธรรมดาไม่ได้ · ระดับสภาพผูกกับความกว้างและชนิดรอย → ความกว้างต้องมีสเกลจึงวัดจากภาพได้ |
| Spalling กะเทาะ | ผิวคอนกรีตหลุดล่อน เล็ก = ลึก <2.5 ซม. หรือ ø ~15 ซม. · ลึกวัดจากภาพไม่ได้ จึงใช้ "เห็นเหล็กไหม" แทน |
| Exposed_Rebar เหล็กโผล่ | เหล็กโผล่พ้นผิว · ภาพบอกไม่ได้ว่าเหล็กเสียหน้าตัดไหม (สนิมขยายตัวได้ถึง ~10 เท่าของเหล็กเดิม) |
| Rust_Stain คราบสนิม | BMMS แค่บอกว่ารอยเปื้อนสนิม/ขี้เกลือมักตามรอยแตก ไม่มีเกณฑ์ระดับแยก → ใช้เป็น **ตัวบ่งชี้ทางอ้อม** ของเหล็กที่เสียหาย |
| Efflorescence คราบเกลือ | คราบขาวจากเกลือตกผลึก บอกว่าคอนกรีตตรงนั้นถูกปนเปื้อน · แยกคราบน้ำกับคราบเกลือจากภาพไม่ได้ จึงรวมประเภทเดียว |
| Honeycomb รูพรุนรังผึ้ง | ช่องว่างในเนื้อคอนกรีตจากการจี้ไม่ดี · BMMS ไม่มีเกณฑ์ระดับ 2 และ 1 |

**2.1.4 ข้อจำกัดของการตรวจด้วยภาพ.** คราบเกลือและเศษซากอาจบังเหล็กเป็นสนิมหรือรอยร้าว คอนกรีตที่หลุดเป็นแผ่นอาจบังเหล็กด้านใน ภาพผิวภายนอกเห็นไม่ได้ และ BMMS เขียนไว้ให้ผู้ตรวจหน้างาน → งานนี้แยก "สิ่งที่ภาพตัดสินได้" ออกจาก "สิ่งที่ต้องใช้ตัวบ่งชี้ทางอ้อม" แล้วรายงานค่าความมั่นใจของระดับที่ให้

### 2.2 การตรวจสอบสะพาน เกณฑ์ประเมินสภาพ และดัชนีสุขภาพ

**2.2.1 การตรวจ 3 แบบของ BMMS.** ตรวจปกติ (routine) ทุก 1–2 ปี ตรวจหยาบ ผู้ตรวจไม่ต้องมีทักษะสะพานสูง · ตรวจหลัก (principal) ทุก 4–6 ปี วิศวกรมีทักษะ ตรวจละเอียดทุกชิ้นส่วน · ตรวจพิเศษ (special) ไม่มีรอบ ใช้เมื่อเกิดความเสียหาย/เหตุฉุกเฉิน ใช้ผู้เชี่ยวชาญและทดสอบแบบไม่ทำลาย ความถี่สั้นลงเมื่อสภาพโดยรวม ≤ ระดับ 3 · **งานนี้อยู่ก่อนการตรวจปกติ/ตรวจหลัก ไม่ใช่การตรวจประเภทใดของ BMMS และไม่แทนวิศวกร**

**2.2.2 เกณฑ์ระดับสภาพ (ตารางที่ 2.3).** ให้เป็นจำนวนเต็ม 6 ระดับ ระดับ 4–0 นิยามด้วย "การซ่อมบำรุงที่ต้องทำ" ไม่ได้นิยามด้วยตัวเลขความเสียหาย

| ระดับ | ชื่อ | ความหมาย (ย่อ) |
|---|---|---|
| 5 | ดีมาก | ดีหรือใหม่ |
| 4 | ดีพอใช้ | ส่วนรับแรง/สำคัญเกณฑ์ดี ซ่อมบำรุงปกติ · ส่วนไม่สำคัญพอใช้ ซ่อมตามกำหนด |
| 3 | พอใช้ | ซ่อมบำรุงตามกำหนดเวลา |
| 2 | ชำรุด | ส่วนรับแรง/สำคัญชำรุด ต้องซ่อมแซมหรือบำรุงพิเศษ |
| 1 | วิกฤต | เสียหายมาก ต้องซ่อมเร่งด่วนหรือบูรณะ |
| 0 | วิบัติ | ต้องทุบทิ้งสร้างใหม่ |

**ความกว้างรอยร้าวที่ใช้แบ่งระดับ (ตารางที่ 2.4)** — เกณฑ์ตัวเลขที่สำคัญที่สุดของงานนี้:

| ระดับ | RC | PC (คานตามยาว) | เงื่อนไขอื่น |
|---|---|---|---|
| 4 | < 1.6 มม. | < 0.10 มม. | hairline |
| 3 | 1.6–3.2 | 0.10–0.23 | รอยเล็ก อาจมีขี้เกลือ/คราบน้ำ/สนิม |
| 2 | 3.2–4.8 | 0.25–0.76 | รอยกลาง · รอยจากเหล็กเป็นสนิม |
| 1 | > 4.8 | > 0.76 | รอยใหญ่ · รอยจากสนิม · รอยเฉือน/ดัดที่กระทบกำลัง (ทุกขนาด) |

ข้อสังเกตของเล่ม: BMMS ไม่ระบุที่มาของตัวเลขเหล่านี้ และ **ช่อง 0.23–0.25 มม. ของ PC ไม่ได้กำหนดระดับไว้** (ระดับ 3 พิมพ์ถึง 0.23 ระดับ 2 เริ่ม 0.25) ระดับ 2 และ 1 ผูกกับเงื่อนไขที่ผู้ตรวจต้องใช้ดุลยพินิจหน้างาน

**เกณฑ์เชิงบรรยายของความเสียหายอื่น (ตารางที่ 2.5):** กะเทาะ: ระดับ 4 หลุดเล็กน้อยไม่ถึงเหล็ก → ระดับ 3 หลายจุดหรือบริเวณกว้างแต่ไม่ถึงเหล็ก → ระดับ 2 ถึงเหล็ก → ระดับ 1 ถึงเหล็กหลายจุดหรือบริเวณกว้าง · เหล็กเสริม: ระดับ 3 เสียหายถึงเหล็กในจุดที่ไม่กระทบกำลัง → ระดับ 2 เหล็กเป็นสนิม (PC เห็นลวดอัดแรงบางส่วน) → ระดับ 1 เหล็กเสียหายมาก (PC เห็นลวดจำนวนมาก, แอ่นตัวผิดปกติ) · BMMS **ไม่มีเกณฑ์เป็นพื้นที่ (ตร.ม./%)** และไม่มีเกณฑ์ระดับแยกของคราบสนิม

**BMMS รวมระดับเป็นสภาพสะพานด้วย "ค่าต่ำสุด" ไม่ใช่ค่าเฉลี่ย:** ใช้ระดับแย่สุดของชิ้นส่วนเป็นตัวแทนแต่ละกลุ่ม แล้วเอาค่าต่ำสุดของส่วนบนและส่วนล่างเป็นสภาพรวม (ส่วนประกอบรองไม่เข้าสูตร) เช่น ส่วนบน 4 ส่วนล่าง 3 ส่วนรอง 1 → สภาพรวมระดับ 3 · BMMS ไม่มีน้ำหนักถ่วงและไม่มีดัชนี 0–100

**กฎตัดสินระดับจากภาพ (ตารางที่ 2.6)** — เพราะเกณฑ์ BMMS เขียนให้คนยืนหน้างาน ผู้จัดทำจึงแปลงเป็นกฎที่ภาพตัดสินได้ (เป็นข้อกำหนดของผู้จัดทำ):

| ประเภท | วิธีตัดสินระดับจากภาพ | ข้อจำกัด |
|---|---|---|
| Crack | วัดความกว้างด้วยสเกลเลเซอร์เทียบตาราง 2.4 · ถ้ามี Rust_Stain ทับ ระดับไม่ดีกว่า 2 · **ถ้าวัดไม่ได้ (ไม่มีสเกลหรือ < 3 พิกเซล) ให้ระดับ 3 ตั้งต้นและค่าความมั่นใจต่ำ** | รอยเฉือน/ดัดที่กระทบกำลัง ภาพตัดสินไม่ได้ จึงไม่ให้ระดับ 1 จากเหตุนี้ |
| Spalling | ไม่เห็นเหล็ก: ระดับ 4 (จุดเดียว/น้อย) หรือ 3 (หลายจุด/กว้าง) · เห็นเหล็ก (มี Exposed_Rebar ซ้อน): ระดับ 2 · เหล็กโผล่หลายจุด/กว้าง: ระดับ 1 | ใช้ "เห็นเหล็ก" แทนความลึก |
| Exposed_Rebar | ระดับ 3 ถ้าไม่มีสัญญาณเหล็กเสียหน้าตัด · ระดับ 2 ถ้ามี Rust_Stain ติดเหล็กและพื้นที่มากกว่าเหล็ก · ระดับ 1 ถ้าโผล่หลายจุด/กว้าง | ภาพบอกการเสียหน้าตัดไม่ได้ → ค่าความมั่นใจต่ำ |
| Honeycomb | ระดับ 4 ถ้าเล็ก/จุดเดียว · ระดับ 3 ถ้าหลายจุด/กว้าง | BMMS ไม่มีระดับ 2 และ 1 |
| Efflorescence | ระดับ 3 เสมอ | รวมคราบน้ำและเกลือ |
| Rust_Stain | เดี่ยวๆ ระดับ 3 · ทับ Crack ดัน Crack เป็นระดับ 2 · ติด Exposed_Rebar และพื้นที่มากกว่า ดัน Exposed_Rebar เป็นระดับ 2 | BMMS ไม่มีเกณฑ์ระดับของคราบสนิม |

**2.2.3 EHI และ T-BHI.** คำนวณตามวิธีของโครงการแพลตฟอร์มดิจิทัลแฝด (ศุภศิษฏ์ ศรีวรานันท์ และคณะ, 2569ข) โครงสมการตามดัชนีสุขภาพของ AASHTO (2018, สมการ 3.3.1.3-1 และ 3.3.1.3-2)

```
EHI_e = 100 × Σ ( C_k × y_e(k) )   k = 5 ถึง 0                  (สมการ 2.1)
T-BHI = Σ ( q_e × W_e × EHI_e ) ÷ Σ ( q_e × W_e )              (สมการ 2.2)
```

- y_e(k) = สัดส่วนพื้นที่ของชิ้นส่วนชนิด e ที่อยู่ที่ระดับ k · C_k = ค่าสัมประสิทธิ์ของระดับ k · q_e = ปริมาณชิ้นส่วนชนิด e · W_e = น้ำหนักความสำคัญ
- **ค่า C และสถานะที่ตรงกับช่วงคะแนน (ตารางที่ 2.7):** ถ้าทั้งชิ้นส่วนอยู่ระดับเดียว

| ระดับ | ชื่อระดับ (BMMS) | C | EHI | สถานะตามช่วงคะแนน |
|---|---|---|---|---|
| 5 | ดีมาก | 1.00 | 100 | ดีมาก |
| 4 | ดีพอใช้ | 0.83 | 83 | พอใช้ |
| 3 | พอใช้ | 0.67 | 67 | ชำรุด |
| 2 | ชำรุด | 0.33 | 33 | วิกฤต |
| 1 | วิกฤต | 0.17 | 17 | วิบัติ |
| 0 | วิบัติ | 0.00 | 0 | วิบัติ |

- ที่มาของ C: AASHTO กำหนดค่าปลายทาง (1 และ 0) แล้วเปิดให้เจ้าของระบบกำหนดค่ากลางเอง ผู้จัดทำแบ่ง 0.67/0.33 เชิงเส้น และกำหนด 0.83/0.17 เอง เพราะ AASHTO ไม่มีระดับที่ตรงกัน
- **ข้อสังเกตที่เล่มเขียนเอง:** ดัชนีแบบถ่วงน้ำหนัก ทำให้ความเสียหายรุนแรงเฉพาะจุดถูก "เจือจาง" ด้วยส่วนที่ไม่เสียหาย ขณะที่หลักค่าต่ำสุดของ BMMS ไม่เจือจาง จึงต้องมี **กฎบังคับสถานะ** (3.7.6) และต้องรายงานระดับของชิ้นส่วนที่แย่ที่สุดควบคู่ดัชนี
- (ตาราง 2.7 คอลัมน์ "สถานะ" ถูกอาจารย์ตั้งข้อสังเกต ดูส่วนที่ 7)

### 2.3 การเรียนรู้เชิงลึกสำหรับตรวจหาและแบ่งส่วนภาพ

**2.3.1 3 รูปแบบ และความท้าทาย.** จำแนก (classification: ภาพมีความเสียหายชนิดใด) · ระบุตำแหน่ง (localization: ให้กรอบ) · แบ่งส่วน (segmentation: ระดับพิกเซลเป็น mask) → **มีแต่การแบ่งส่วนที่ให้พื้นที่** ซึ่งเป็นตัวตั้งและตัวหารของสัดส่วนในดัชนี (Sony et al., 2021) รีวิว CNN มากกว่า 100 ฉบับสรุปความท้าทาย: ข้อมูลไม่สมดุล ขยายไปโครงสร้างอื่นยาก ผลบวกเท็จจากเงา/แสง โมเดลเป็นกล่องดำ และแนะนำให้รายงานอัตราผลลบเท็จควบคู่ความแม่นยำ

**ตัวเลขของงานอื่นที่เล่มยก (เทียบกันตรงๆ ไม่ได้):**

| งาน | ผล |
|---|---|
| Çelik et al. (2025) แบ่งส่วนความเสียหาย 8 ประเภท 2,070 ภาพ | mean IoU **20.6%** (รูพรุนรังผึ้งเพียง 2.1%) |
| Chou et al. (2026) 700 ภาพ | mAP50 50.5% |
| Zhang & Chen (2026) กรอบ 5 ประเภท 8,924 ภาพ | mAP50 72.51%, recall 65.61% |

ข้อสรุปของเล่ม: การตรวจหลายประเภทบนสะพานคอนกรีต **ยังไม่แม่นพอที่จะวางใจโมเดลเดียวโดยไม่มีกลไกกันพลาด** → เหตุผลที่ออกแบบเป็นคัดกรองขั้นแรก

**2.3.2 แบ่งส่วนชิ้นส่วนและ YOLO.** YOLO26 (Ultralytics) ทำงานครบวงจรโดยไม่ต้องกำจัดกรอบซ้อน (NMS) รุ่น YOLO26-seg สร้าง mask (Jocher et al., 2026) ตัวเลขของผู้พัฒนาเป็นข้อมูลทั่วไป ไม่ใช่สะพาน · เลือกเพราะฝึกเองบนข้อมูลงานได้ และให้ mask งานก่อนหน้า: Karim et al. (2021) ใช้ Mask R-CNN แบ่งส่วนชิ้นส่วนสะพานจากวิดีโอทางอากาศ ใช้ภาพติดป้ายเพียง 66 ภาพ ได้ precision 91.8% recall 93.6% (แสดงว่าชิ้นส่วนสะพานแบ่งได้ด้วยข้อมูลไม่มาก) · BR-DETR ให้กรอบ ไม่ให้พื้นที่จริง · Zheng et al. (2022) แบ่งรอยร้าวด้วย Mask R-CNN (MIoU 0.81) แล้ววัดความกว้าง แต่ใช้ภาพระยะใกล้ ไม่ใช่โดรน

**2.3.3 SAM และ SAM 3.** SAM (Kirillov et al., 2023) รับพรอมต์ (จุด/กรอบ) แล้วคืน mask · SAM 3 (Carion et al., 2025) รับทั้งแนวคิดและภาพ · Kuttuva & Prawin (2026) ให้ YOLO11 ส่งกรอบเป็นพรอมต์ให้ SAM แบบไม่ฝึกเพิ่ม ได้ Dice รอยร้าว 0.771–0.820 (YOLO11n-seg ที่ฝึกด้วยป้ายพิกเซลได้ 0.705) พรอมต์แบบกรอบดีกว่าจุดเดี่ยว แต่ช่วงความเชื่อมั่นซ้อนกัน รอยบางมากอาจมีพิกเซลน้อยเกินไปจะได้ mask แม่น · Çelik et al. (2025) พบ SAM2 ไม่เหมาะกับความเสียหายขอบไม่คม · Malaisree et al. (2026) (พรีพรินต์) ปรับ SAM 3 ด้วย LoRA ได้ IoU บนผนังอุโมงค์เพิ่มจาก 0.017 เป็น 0.338 → ข้อสรุป: **SAM ไม่ปรับแต่งยังไม่พอสำหรับรอยร้าว/ขอบไม่คม แต่ LoRA ช่วยได้มาก งานนี้จึงปรับแต่ง SAM 3 และส่งกรอบเป็นพรอมต์**

**2.3.4 แบบจำลองภาษาภาพ.** Qwen-VL ระบุตำแหน่งวัตถุด้วยกรอบ/จุดได้ · Qwen3-VL มีรุ่นหนาแน่น 2B–32B และรุ่น mixture-of-experts · Qwen3.6-35B-A3B: พารามิเตอร์รวม 35 พันล้าน ใช้จริงราว 3 พันล้านต่อโทเค็น รับภาพได้ สัญญา Apache-2.0 น้ำหนัก BF16 ราว 70 GB (ผู้จัดทำคำนวณ) จึงอาจต้องลดความละเอียดน้ำหนักหรือใช้ Qwen3-VL ขนาดเล็กลง · Çelik et al. (2026) ทบทวน 13 งาน VLM กับสะพาน ทุกงานให้ชนิดความเสียหาย แต่ไม่มีงานใดเชื่อมกับระดับสภาพ ระดับสภาพต้องใช้การวัดเชิงเรขาคณิตที่ภาพสีอย่างเดียวให้ไม่ได้ และการระบุตำแหน่งด้วยข้อความร่วมกับการแบ่งส่วน (รวม SAM 3) ยังไม่ถูกประเมินบนสะพาน · Zhang & Liu (2025) ต้องใช้ YOLO11x ให้กรอบแก่ Qwen2-VL เพราะ VLM ทั่วไปหาตำแหน่งความเสียหายเล็กอย่างรอยร้าวไม่แม่น · Chou et al. (2026) ใช้ Llama 3.2 Vision + LoRA เขียนคำบรรยาย ไม่ระบุตำแหน่ง · **ยังไม่พบงานที่รายงานความแม่นของการให้กรอบความเสียหายคอนกรีตด้วย VLM ที่ปรับแต่งแล้ว** · VLM อาจ "ภาพหลอน" (hallucination: ตอบสิ่งที่ไม่มีในภาพ) และให้เหตุผลเชิงพื้นที่อ่อน → งานนี้ให้ Qwen ตอบเฉพาะ **ชนิดและกรอบ** ไม่ตอบขนาดหรือระดับ และตรวจโครงสร้างคำตอบทุกรายการก่อนใช้

**2.3.5 การปรับแต่งแบบประหยัดพารามิเตอร์ (PEFT/LoRA).** Chou et al. ปรับ Llama 3.2 Vision 11B ด้วย LoRA + ลดน้ำหนักเหลือ 4 บิตบน GPU ตัวเดียว · Malaisree et al. ปรับ SAM 3 เพียง 0.121–1.341% ของพารามิเตอร์ · ผลขึ้นกับจำนวน/คุณภาพข้อมูล Çelik et al. (2025) ว่าต้องใช้ชุดข้อมูลระดับห้าหลัก → งานนี้เพิ่มข้อมูลเป็นรอบและวัดผลหลังแต่ละรอบ

**2.3.6 ตัวชี้วัด.** precision, recall, IoU = |A∩B| ÷ |A∪B| (สมการ 2.3), Dice = 2|A∩B| ÷ (|A|+|B|) (สมการ 2.4) · ตรวจจับ "ถูก" เมื่อ IoU ≥ เกณฑ์ (เช่น 0.5) · ระวังอ่านตัวเลขงานอื่น: ชุดข้อมูล/วิธีประเมินต่างกัน และค่าสูงสุดรายประเภทไม่ใช่ค่าเฉลี่ย (เช่น F1 99% ในบทคัดย่อของ Çelik 2025 เป็นค่าสูงสุดรายประเภท ค่าเฉลี่ยการให้ระดับคือ 72.0%) → งานนี้รายงานรายประเภทและ recall ควบคู่เสมอ

**2.3.7 ข้อสรุป: ทำไมอัตโนมัติเต็มตัว.** งานที่เชื่อมไปถึงการให้ระดับยังพึ่งผู้ตรวจในวงจร (Çelik 2025; ศุภศิษฏ์ 2569ก) งานนี้เลือกอัตโนมัติ เพราะเป็นการคัดกรองขั้นแรกที่รันกับภาพจำนวนมาก และชดเชยด้วย 3 กลไกกันพลาด: (1) ค่าความมั่นใจ (2) กฎบังคับสถานะ (3) การวัดผลที่รายงานผลลบเท็จและทิศของความผิดพลาด

### 2.5 การหาขนาดจริงจากภาพ (หัวข้อที่สำคัญมาก)

**2.5.1 ขนาดต่อพิกเซลจากระยะถ่าย.** วิธีทั่วไป: สมการเลนส์บาง 1/u + 1/v = 1/f (Liu 2020) เมื่อวัตถุไกลมาก Li et al. (2022): W_จริง = ((L − f) ÷ f) · W_ภาพ (สมการ 2.5) · Peng et al. (2021) ใช้ระยะจากเลเซอร์วัดระยะ + ความยาวโฟกัส + ขนาดเซนเซอร์ ได้ 0.105–0.142 มม./พิกเซล ที่ระยะ 2.07–2.64 ม. · **ข้อจำกัด:** ต้องรู้ระยะกล้อง–ผิว ซึ่งไม่ได้บันทึกในภาพ และขนาด/พิกเซลแปรตามระยะ เครื่องวัดระยะในตัว Matrice 4E คลาด ≤ 0.3 ม. ที่ 1–3 ม. จะทำให้สเกลคลาด **10% ที่ 3 ม. และ 30% ที่ 1 ม.** (ผู้จัดทำคำนวณ) · Zhang et al. (2026): ใช้ GSD ค่าเดียวทั้งภาพทำให้เอนเอียงใกล้ขอบภาพและเมื่อถ่ายเฉียง

**2.5.2 การนับ pixel + แก้ความบิดเบี้ยวเชิงทัศนมิติ.** อีกแนวทาง: วางหรือฉายวัตถุที่รู้ขนาดจริงลงภาพ (เครื่องหมายระนาบ, เสาที่รู้เส้นผ่านศูนย์กลาง, ไม้บรรทัด, บล็อก 100 มม.) ต้องมีวัตถุอ้างอิงในภาพ · **เลเซอร์ 4 จุด** ฉายสี่จุดเป็นสี่เหลี่ยมจัตุรัสที่รู้ขนาดจริง **สเกล s = d ÷ p** (สมการ 2.6) เมื่อ d = ระยะจริงระหว่างจุดข้างเคียง (มม.) และ p = ระยะของสองจุดเดียวกันในภาพ (พิกเซล) → s มีหน่วย มม./พิกเซล · ถ้ากล้องเฉียง จัตุรัสจะกลายเป็นสี่เหลี่ยมคางหมู → ใช้ **homography** จับคู่ 4 จุดในภาพกับ 4 จุดจริงเพื่อหาสเกลทุกตำแหน่งบนระนาบนั้น (Zhang 2026 สมมติผิวเป็นระนาบเฉพาะที่ราว 0.5–1 ม.; Li 2022 ใช้การแปลงเชิงเส้นแบบ affine ไม่ใช่โฮโมกราฟีเต็มรูป)

**2.5.3 เลเซอร์/เซนเซอร์วัดระยะบนโดรน (ตารางที่ 2.11)** — 3 แนวทาง: เลเซอร์ขนานระยะห่างคงที่ (Li 2022) · เครื่องวัดระยะประกอบเป็นรูปทรงอ้างอิง (Zhang 2026; Peng 2021) · เลเซอร์กากบาท+เซนเซอร์วัดระยะ (Zuo 2026)

| งาน | อุปกรณ์/วิธี | ระยะ/รอยที่ทดสอบ | ผล |
|---|---|---|---|
| Li et al. (2022) | เลเซอร์ขนาน 4 ตัว d = 100 มม. + อัลตราโซนิก · แปลงเป็นจัตุรัสแล้วหาสเกล | 0.50–0.72 ม. · 12 รอย กว้าง 0.16–0.66 มม. | อัตราส่วนวัด/อ้างอิงเฉลี่ย 0.97 (CV 7.59%) เทียบวิธีคำนวณจากระยะ 1.15 (CV 15.73%) |
| Zhang et al. (2026) | เครื่องวัดระยะเลเซอร์ 4 ตัว (±1 มม.) ปรับมุมด้วยมอเตอร์ · homography | ป้ายอ้างอิง 0.8–20 มม. ที่ 2, 4, 6 ม. มุม 0° และ 45° · สะพานจริง 4 รอย 0.35–1.30 มม. | ป้าย 0.8 มม. คลาด ~2.5% · สะพานจริง MAE 0.038 มม. · แดดตรงทำให้หาจุดไม่ได้ |
| Peng et al. (2021) | เครื่องวัดระยะเลเซอร์ 3 จุด ซิงก์ชัตเตอร์ · ระยะ+มุมระนาบ+โฟกัส | ท้องพื้นสะพาน 2.07–2.64 ม. · 3 รอย | ความแม่นสัมพัทธ์ 91.5–96.4% · ไม่ทดสอบรอยบางกว่า 0.7 มม. |
| Zuo et al. (2026) | เลเซอร์กากบาท 150 mW + ToF 3 ตัว หนัก ~190 g | 0.49–3.58 ม. · 39 รอย เทียบผู้ตรวจ 6 คน | รอยที่ผู้ตรวจวัดได้ < 0.3 มม. ถูกวัดเกินเฉลี่ยราว 2.5 เท่า |

Li et al. (2022) ใกล้แผนงานนี้ที่สุด แต่การเทียบกับวิธีคำนวณจากระยะมีตัวแปรปน (วิธีหลังไม่ได้แก้ perspective) จึงสรุปไม่ได้ว่าเลเซอร์ดีเพราะตัวเลเซอร์เอง · การทดสอบของ Zhang (ป้ายอ้างอิงหลายระยะและมุมก่อนไปรอยจริง) เป็นแบบอย่างของ 3.6.4 · **งานนี้ไม่ใช้ GSD** เพราะต้องรู้ระยะกล้อง–ผิวซึ่งคลาดเคลื่อน และการควบคุมโฟกัส/ระยะถ่ายให้คงที่ใต้สะพานทำได้ยากตามที่พบจากการพูดคุยกับผู้ปฏิบัติงานหน้างาน

**2.5.4 ขีดจำกัดความละเอียดภาพ.** Liu et al. (2020): ความกว้างรอยที่เล็กที่สุดตรวจพบ = 1 หรือ 3 พิกเซล รอยบางสุด (0.45 มม.) ถูกวัดเกินจริง 249% · รอยที่กว้างน้อยกว่า 2 เท่าของความกว้างต่ำสุด คลาดเฉลี่ยราว 100% · รอยที่กว้างตั้งแต่ 3 เท่าขึ้นไป คลาดราว 6–7% (ผู้จัดทำคำนวณ) · Zuo (2026): ระบบวัดรอยละเอียดเกินจริง · Zheng (2022): รอยกว้างกว่า 0.5 มม. ถูกวัดเกินราว 28–35% แม้ภาพระยะใกล้ 0.025 มม./พิกเซล → **ใช้เกณฑ์ 3 พิกเซลเป็นขอบความน่าเชื่อถือ**

**ประมาณการความละเอียดที่ระยะถ่ายต่างๆ (ตารางที่ 2.12)** คำนวณจากสเปกกล้อง: ขนาด 1 พิกเซล = (0.8 × 2D tan 42°) ÷ 5,280 (D = ระยะถ่าย) ใช้ประเมินความเป็นไปได้เท่านั้น ไม่ใช้แปลงขนาดในกระบวนการ

| ระยะถ่าย | 1 พิกเซลบนผิว | ความกว้างต่ำสุดที่เชื่อถือได้ (≈ 3 พิกเซล) |
|---|---|---|
| 1 ม. | 0.27 มม. | 0.82 มม. |
| 2 ม. | 0.55 มม. | 1.64 มม. |
| 3 ม. | 0.82 มม. | 2.46 มม. |
| 5 ม. | 1.36 มม. | 4.09 มม. |

**อ่านตารางนี้อย่างไร:** ที่ 2 ม. วัดได้เชื่อถือขั้นต่ำ ~1.6 มม. = ขอบระหว่างระดับ 4 และ 3 ของ RC (1.6 มม.) ที่ 3 ม. ขึ้นไปจึงแยกสองระดับนี้ด้วยความกว้างไม่ได้ ส่วนรอย PC ระดับ 4–3 (0.10–0.23 มม.) **แคบกว่า 1 พิกเซลแล้วที่ 1 ม.** → การประเมินรอยของคานหลักต้องพึ่งตัวบ่งชี้ทางอ้อมและให้ค่าความมั่นใจต่ำ และจะวัดขีดจำกัดจริงใน 3.6.4

**2.5.5 เซนเซอร์วัดระยะ + ข้อสรุป.** อัลตราโซนิกวัดจากเวลาคลื่นเสียงสะท้อน, ToF เลเซอร์วัดจากเวลาแสงไปกลับ · เครื่องวัดระยะในตัว Matrice 4E วัดได้จุดเดียวและหยาบเกินไปสำหรับสเกลระยะใกล้ จึงใช้เป็นข้อมูลประกอบ · งานที่ศึกษาทดสอบระยะราว 0.5–6 ม. (6 ม. เป็นป้ายบนผนัง ไม่ใช่รอยจริง) **ไม่พบ**: งานที่รายงานแสงเป็นตัวเลข, งานเทียบวิธีหาสเกลหลายแบบพร้อมกันด้วยแถบอ้างอิง, งานทดสอบกับท้องคาน PC โดยตรง → งานนี้เลือกเลเซอร์ 4 จุดเป็นวิธีหลักและทดสอบหลายระยะ มุม แสง กับ crack scale ใน 3.6.4

**2.6.2 ช่องว่างงานวิจัย 6 ข้อ** (ตามที่เปเปอร์เขียนเอง หรือที่ผู้จัดทำตรวจไม่พบ ไม่ใช่การสืบค้นครบทั้งโลก):

1. ส่วนใหญ่หยุดที่การแบ่งส่วน ไม่ถึงระดับสภาพ (ที่ไปถึงใช้ข้อความบันทึกตรวจและปริมาณที่ผู้ตรวจกรอกเอง)
2. VLM กับสะพานยังไม่เชื่อมระดับสภาพ และ (จนถึงต.ค. 2026) ยังไม่พบงานที่ให้ VLM fine-tune เป็นผู้ให้กรอบ แล้วส่งให้ SAM 3 วาด mask บนภาพโดรนสะพาน
3. ขนาดความเสียหายยังไม่ได้มาจากการวัดจริง (รายงานเป็นพิกเซลหรือ GSD สมมติ)
4. การทดสอบเลเซอร์ยังไม่ครอบคลุมใต้สะพาน (ระยะที่ทดสอบกับรอยจริง ~0.5–2.6 ม. ไม่พบรายงานแสงเป็นตัวเลข รอยละเอียดใกล้ขีดจำกัดพิกเซลยังวัดไม่ดี)
5. ภาพโดรนของคาน PC ชนิดคานตัวไอ ไม่พบงานที่ใช้เป็นข้อมูลหลัก (ยกเว้นรายงาน 2569ก ที่ใช้กรอบ+คนยืนยัน)
6. ความแม่นของโมเดลหลายประเภทบนสะพานยังต่ำ รูพรุนรังผึ้งยากเป็นพิเศษ → สนับสนุนการออกแบบเป็นคัดกรองขั้นแรก

**2.6.3 สิ่งที่งานนี้ทำเพิ่ม 5 ข้อ:** (1) แปลงผลแบ่งส่วน → ระดับ 0–5 → EHI → T-BHI ด้วยกฎตรวจย้อนได้ตามเกณฑ์ที่เผยแพร่ (3.7) (2) ทดสอบลำดับ Qwen ให้กรอบ → SAM 3 วาด mask บนภาพโดรนสะพาน วัดผลแยกขั้น (3.5.3, 3.8) (3) ใช้เลเซอร์ 4 จุดเป็นการนับ pixel ทดสอบความแม่นกับ crack scale (3.6) (4) ใช้ภาพโดรนของสะพาน PC คานตัวไอ ทั้งชุดเดิมและใหม่ (3.3) (5) ทำงานอัตโนมัติ ชดเชยด้วยค่าความมั่นใจและกฎบังคับสถานะ และวัดผลเทียบวิศวกร (3.7.6, 3.8)

### 3.3 สะพานกรณีศึกษาและแผนเก็บข้อมูล

**3.3.1 สะพาน:** สะพานเฉลิมพระเกียรติ 72 พรรษา จ.ฉะเชิงเทรา (รหัส 144210087) ข้ามแม่น้ำบางปะกง ทางหลวงหมายเลข 304 เปิดใช้ พ.ศ. 2542 · PC 4 ช่องจราจร ยาว 647 ม. กว้าง 21.6 ม. ชนิดคานตัวไอ · BMMS ตรวจล่าสุด 10 ก.ย. 2567 ได้ระดับความเสียหายโดยรวม **2 (ชำรุด)** · คานหลักเป็น PC ใช้เกณฑ์ PC กับคานหลัก ส่วนเสาและหัวเสาใช้เกณฑ์ RC (**ยังต้องยืนยันวัสดุจริงกับวิศวกร**) · สำรวจภาคสนาม 13 ต.ค. 2569 (รูปที่ 3.2)

**3.3.2 ชุดข้อมูลเดิม:** จากโครงการ 2569ก บนสะพานเดียวกัน >1,000 ภาพ ช่วงบนบกและกลางน้ำ ถ่ายด้วย Mavic 3 Enterprise บินสูง 20–40 ม. · คานใช้มุมกล้องเฉียง 25–35° บินสองฝั่ง · ตอม่อบินรอบ 360° · ภาพห่างกัน ~2 วินาที ซ้อนกัน ~70–80% · ใช้ฝึก/ทดสอบแบบจำลองใน 3.5 โดยแบ่งตามรอบบิน · **ชุดนี้ไม่มีจุดเลเซอร์และ crack scale และไม่มีภาพใดเห็นชิ้นส่วนครบทั้งชิ้น จึงคิดได้เฉพาะสัดส่วนต่อภาพ**

**3.3.3 ชุดข้อมูลใหม่:** ถ่ายด้วย Matrice 4E บินแยกตามชิ้นส่วน พร้อมติดชุดเลเซอร์ 4 จุดและวาง crack scale ในฉาก · ใช้ทดสอบความแม่นของการหาขนาดจริง (3.6.4) และเป็น **ชุดทดสอบอิสระ** ของแบบจำลองและของ T-BHI (3.8) · **รอบบินที่จัดเป็นชุดทดสอบจะไม่นำมาฝึกหรือปรับค่าใดๆ**

**3.3.4 แผนบินและถ่ายภาพ (ตารางที่ 3.2)** ลำดับเดียวกันทุกช่วงสะพาน ภาพแต่ละกลุ่มจึงมีชิ้นส่วนเป้าหมายที่รู้จากบันทึกการบิน:

| ลำดับ | ชิ้นส่วน | ข้อพิจารณา |
|---|---|---|
| 1 | คาน | ถ่ายใต้สะพาน กล้องเงย ≤ 35° ได้ภาพเฉียงท้องคานและด้านข้าง · แสงน้อย ให้ระบบมองภาพช่วยลอยตัว · ต้องเห็นจุดเลเซอร์ครบ 4 จุด |
| 2 | หัวเสา | ถ่ายรอบหัวเสาหลายด้านระยะใกล้ตามช่วงที่ทดสอบได้ใน 3.6.4 รักษาระยะปลอดภัย |
| 3 | ตอม่อ | ถ่ายรอบทิศ ตอม่อกลางน้ำระวังแสงสะท้อนผิวน้ำและความปลอดภัยเหนือน้ำ |
| 4 | คานยาว | ถ่ายต่อเนื่องตามแนวช่วงสะพาน รักษาระยะและมุมกล้องคงที่ให้สเกลสม่ำเสมอ |
| 5 | พื้นสะพาน | ถ่ายผิวด้านบนเป็นลำดับสุดท้าย ต้องประสานงานกรมทางหลวงเรื่องจราจร กล้องก้ม −90° ถ่ายตั้งฉากผิวได้ |

**พารามิเตอร์การถ่ายทุกรอบ:**
- (ก) **ระยะและมุม:** ระยะไม่ต่ำกว่า 1 ม. (ตามโฟกัสกล้อง) ช่วงที่ใช้จริงกำหนดจากการบินนำร่อง บันทึกมุมก้มเงยกล้อง (GimbalPitchDegree) ทุกภาพ ถ่ายให้ผิวเอียงน้อยที่สุด
- (ข) **ความซ้อน:** ความเร็วบิน/ช่วงเวลาถ่าย (≥ 0.5 วินาที) ให้ภาพติดกันซ้อนน้อยที่สุดที่ยังครอบคลุมไม่มีช่องว่าง ค่าเป้าหมายเริ่มต้น **ไม่เกิน 50% ตามแนวบิน** ปรับตามผลบินนำร่อง
- (ค) **จุดเลเซอร์และ crack scale** ต้องเห็นครบ 4 จุดและไม่ถูกแดดตรงกลบ ไม่เห็นให้ถ่ายซ้ำ · crack scale ติดข้างรอยที่เลือกเป็นชุดทดสอบ
- (ง) **แสง อากาศ ความปลอดภัย:** บันทึกเวลา ลักษณะแสง ความเร็วลมทุกรอบ ไม่บินเมื่อสภาพอากาศเกินข้อกำหนดผู้ผลิต ขออนุญาตกรมทางหลวงก่อนเข้าพื้นที่ ไม่บินเหนือช่องจราจรที่มีรถ

**3.3.5 การจัดการข้อมูล:** (1) ข้อมูลดิบ (ภาพต้นฉบับ+EXIF) **ไม่แก้ไข** งานทุกขั้นทำบนสำเนา และสำรองภายในวันเดียวกับที่เก็บ อย่างน้อยสองที่ (2) แยกโฟลเดอร์ตามรอบบิน และรอบบินหนึ่งอยู่ในชุดเดียวตลอด (ฝึก/ตรวจสอบ/ทดสอบ) เพื่อกันข้อมูลรั่ว (3) บันทึกรายการรอบบิน: วันที่ เวลา สภาพอากาศ ชิ้นส่วนเป้าหมาย ช่วงสะพาน ชื่อรอบบิน

### 3.4 คัดเลือกภาพและจำแนกประเภทชิ้นส่วน

**3.4.1 คัดภาพ** (ไม่ลบภาพต้นฉบับ แค่ตัดออกจากรายการที่ใช้) ด้วย 3 เกณฑ์: **ความคมชัด** (ความแปรปรวนของค่า Laplacian เทียบเกณฑ์จากบินนำร่อง) · **แสง** (สัดส่วนพิกเซลที่ถูกตัดที่ดำสุด/ขาวสุด) · **จุดเลเซอร์** (ภาพชุดใหม่ที่ใช้วัดขนาดต้องหาจุดได้ครบ 4 ภาพที่ไม่ครบยังใช้กับ 3.5 ได้ แต่ถือว่าไม่มีสเกล และรอยร้าวในภาพนั้นให้ค่าความมั่นใจต่ำ)

**3.4.2 จำแนกประเภทชิ้นส่วนระดับภาพ:** ตัดสินว่าภาพแต่ละภาพมีชิ้นส่วนชนิดใด เพื่อจัดกลุ่มก่อนรวมผล ป้ายได้ 2 ทาง: ป้ายตั้งต้นจากบันทึกการบิน (ใช้กับภาพชุดใหม่และระหว่างที่โมเดลยังไม่พร้อม) และผลแบ่งส่วนจาก YOLO26-seg (ป้ายหลัก) · ชิ้นส่วนชนิด e "ปรากฏ" ในภาพ i เมื่อพื้นที่ mask ของชนิดนั้น ≥ สัดส่วนต่ำสุด τ ของพื้นที่ภาพ (กำหนดจากชุดตรวจสอบ) · ภาพที่ไม่พบชิ้นส่วนเป้าหมายตามบันทึกการบินจะถูกแจ้งให้ตรวจ

### 3.5 แบบจำลอง AI

**3.5.1 โครงสร้าง (รูปที่ 3.3).** ทำงานสองส่วนบนภาพต้นฉบับภาพเดียวกัน: **YOLO26-seg** แบ่งชิ้นส่วน 5 ประเภท (เสา คาน หัวเสา พื้น ราว) ให้ mask ซึ่งใช้เป็น **ตัวหาร** ของสัดส่วนความเสียหาย · **Qwen** ระบุตำแหน่งและชนิดความเสียหาย 6 ประเภท แล้วส่ง **กรอบ** ให้ **SAM 3** วาด mask ตามรูปร่างจริง (เลือก mask แทนกรอบเพราะกรอบให้พื้นที่เกินจริง โดยเฉพาะรอยร้าวคดโค้ง)

**3.5.2 แบ่งส่วนชิ้นส่วน (YOLO26-seg).**
- **ข้อมูล:** 2 แหล่ง = ชุดภาพสาธารณะจาก Roboflow ที่มีป้ายชิ้นส่วนเป็นโพลิกอน + ภาพโดรนจริงที่ติดป้ายโพลิกอนเองด้วย LabelMe
- **กติกาติดป้าย:** ติด **เฉพาะสิ่งที่ตาเห็น ไม่ติดระดับ** (ให้โปรแกรมแปลงใน 3.7) · ตอม่อรวมในประเภทเสา · คานทุกชนิดอยู่ในประเภทคาน
- **แบ่งชุด:** ฝึก : ตรวจสอบ : ทดสอบ = 70 : 15 : 15 โดยแบ่ง **ตามรอบบิน** หนึ่งรอบบินอยู่เพียงชุดเดียว (กันข้อมูลรั่ว) และห้ามย้ายภาพออกจากชุดตรวจสอบ/ทดสอบ
- **เพิ่มความหลากหลาย:** เฉพาะชุดฝึก — พลิกแนวนอน, หมุนไม่เกิน ±15°, ปรับความสว่างและความเบลอ, **ไม่พลิกแนวตั้ง**
- **เลือกขนาดโมเดล:** เทียบ YOLO26s-seg, 26m-seg, 26l-seg บนชุดตรวจสอบ แล้วเลือกขนาดที่ดีที่สุดภายในขีดความสามารถของ GPU
- **ตัวชี้วัด:** mAP ของ mask ที่ IoU 0.5 และ 0.5–0.95, recall รายประเภท, IoU ของพื้นที่ mask

**3.5.3 ระบุตำแหน่ง/ชนิดความเสียหาย และสร้าง mask.**
- **Qwen:** เลือก Qwen3.6-35B-A3B เป็นตัวหลัก ให้ตอบเป็น **รายการ JSON ของชนิดและกรอบพิกเซลเท่านั้น ไม่ให้ตอบขนาดหรือระดับ** ตรวจโครงสร้างคำตอบก่อนใช้ รายการที่ไม่ผ่านถูกทิ้งและนับเป็นสถิติ · ปรับแต่งด้วย LoRA จากคู่ "ภาพ + JSON" ที่สร้างอัตโนมัติจากโพลิกอนที่ติดป้าย · ถ้าเครื่องรันไม่ได้ ใช้ Qwen3-VL ขนาดเล็กลง
- **สมมติฐาน:** Qwen ให้กรอบที่ครอบคลุมที่ IoU 0.5 ได้ **ไม่ต่ำกว่า** ตัวตรวจจับ YOLO26 แบบกรอบที่ฝึกด้วยป้ายชุดเดียวกัน (ทดสอบใน 3.8) หากประเภทใดต่ำกว่า **จะใช้กรอบจาก YOLO26 แทนสำหรับประเภทนั้น**
- **SAM 3:** รับกรอบจาก Qwen เป็นพรอมต์แบบกรอบ ได้ 1 mask ต่อ 1 กรอบ · ปรับแต่งด้วย LoRA โดยสร้างกรอบฝึกจากโพลิกอนพร้อมเติมความคลาดเคลื่อนสุ่มของตำแหน่งและขนาด (ให้ทนต่อกรอบที่ Qwen ให้ไม่แม่น) · วัด IoU และ Dice ของ mask เมื่อรับกรอบจริงเทียบกรอบจาก Qwen

**3.5.4 จับคู่ความเสียหายกับชิ้นส่วน.** ส่วนของ mask ความเสียหายที่ทับอยู่ใน mask ชิ้นส่วนใด นับเป็นของชิ้นส่วนนั้น (ใช้ผลภาพเดียวกัน ไม่ข้ามภาพ) · ถ้าคร่อมสองชิ้นส่วน แบ่งตามพิกเซลที่ทับ · ส่วนที่ไม่ทับชิ้นส่วนใดไม่นำไปคำนวณ แต่รายงานเป็น **"ไม่สังกัดชิ้นส่วน"** และแจ้งให้ตรวจเมื่อความเสียหายหนึ่งรายการมีส่วนนี้เกิน **50%**

### 3.6 ชุดอุปกรณ์วัดระยะและการทดสอบความแม่นของขนาด

**3.6.1 หลักการนับ pixel.** ยิงเลเซอร์ 4 จุดที่มีระยะห่างจริง d ที่ทราบ เรียงเป็นสี่เหลี่ยมจัตุรัสลงบนผิว ให้ติดในภาพ (รูปที่ 3.4) **สเกล = d ÷ p มม./พิกเซล** (สมการ 2.6) เมื่อ p = ความยาวด้านเดียวกันที่วัดในภาพ · **ไม่ต้องรู้ระยะกล้องถึงผิว** จึงไม่ใช้ขนาดต่อพิกเซลจากการคำนวณ

**3.6.2 ชุดเลเซอร์ (ติดตั้งเพิ่มบนโดรน).**
1. **การจัดวาง:** เลเซอร์ 4 ตัว ลำแสงขนานกัน เรียงเป็นสี่เหลี่ยมจัตุรัสด้านยาว d ทดสอบอย่างน้อย 2 ค่า = 100 มม. (ตาม Li 2022) และค่าที่มากกว่าภายในข้อจำกัดของโครงยึด
2. **สีและความปลอดภัย:** สีที่แยกจากผิวคอนกรีตได้ชัดในแสงกลางวัน กำลังต่ำสุดที่ยังเห็นจุด ระวังความปลอดภัยต่อดวงตาตามมาตรฐานผลิตภัณฑ์เลเซอร์
3. **น้ำหนักและการยึด:** รวมไม่เกิน 200 กรัม (ข้อจำกัดของ Matrice 4E) ลำแสงขนานกับแกนกล้องและไม่บังเซนเซอร์ของโดรน
4. **สอบเทียบความขนาน:** ถ่ายจุดเลเซอร์บนแผ่นเรียบที่ระยะ **1, 2, 3 และ 5 ม.** ถ้าระยะระหว่างจุดเปลี่ยนตามระยะ แสดงว่าลำแสงไม่ขนาน ต้องปรับหรือชดเชยด้วยสมการสอบเทียบ

**3.6.3 หาจุดเลเซอร์ → คำนวณสเกล → วัดความกว้างรอย.**
1. **หาจุด:** แปลงภาพเป็น HSV คัดพิกเซลที่ตรงกับสีเลเซอร์ หาก้อนวงกลมที่ใหญ่ที่สุด 4 ก้อน หาจุดศูนย์กลางระดับย่อยพิกเซล **ต้องได้ 4 จุดพอดีเรียงเป็นสี่เหลี่ยมนูน** ภาพที่ไม่ผ่านถือว่าไม่มีสเกลและให้ค่าความมั่นใจต่ำ
2. **สเกล:** แก้ perspective ด้วย homography จาก 4 จุดไปยังสี่เหลี่ยมจัตุรัสด้านยาว d · **สมมติว่าผิวบริเวณจุดเลเซอร์และรอยร้าวอยู่ในระนาบเดียวกัน** ถ้าผิวโค้ง/ขรุขระมาก ลดค่าความมั่นใจ · สเกลใช้ได้ภายในภาพนั้นเท่านั้น
3. **ความกว้างรอย:** สร้างเส้นกึ่งกลางของ mask รอยร้าวจาก SAM 3 วัดความกว้างทุกจุดจากแผนที่ระยะ แปลงเป็น มม. ด้วยสเกลของภาพ ใช้ **เปอร์เซ็นไทล์ที่ 95** เป็นค่าตัวแทน และรายงานค่าสูงสุดควบคู่ · **ความกว้าง < 3 พิกเซล = วัดไม่ได้อย่างน่าเชื่อถือ** ให้ค่าความมั่นใจต่ำ และไม่ใช้ตัวเลขนั้นตัดสินระดับโดยตรง

**3.6.4 ทดสอบความแม่นของขนาด (ตารางที่ 3.3).** ใช้ crack scale เป็นค่าอ้างอิง วางข้างรอยร้าวจริงหรือบนผิวทดสอบ ถ่ายให้เห็นทั้งจุดเลเซอร์และ crack scale แล้วเทียบกับค่าที่ทราบ

| ตัวแปร | ระดับที่ทดสอบ |
|---|---|
| ระยะถ่าย | อย่างน้อย 3 ระดับภายในช่วงที่ใช้จริงใต้สะพาน ไม่ต่ำกว่า 1 ม. (ค่าตั้งต้น 1.5, 3, 5 ม. ปรับตามบินนำร่อง) |
| มุมถ่ายต่อผิว | 0°, 15°, 30°, 45° (ท้องคานถ่ายเฉียงได้เพราะกล้องเงยได้ ≤ 35°) |
| แสง | แดดตรง, ร่มเงา, ใต้สะพาน |
| ความกว้างเส้นอ้างอิง | หลายขนาดให้ครอบคลุมค่าขอบเขตของเกณฑ์ BMMS (ตาราง 2.4) |
| ลักษณะผิว / จำนวนซ้ำ | เรียบและขรุขระ · อย่างน้อย 3 ภาพต่อเงื่อนไข |

**ตัวชี้วัด:** (ก) อัตราที่หาจุดเลเซอร์ได้ครบ 4 จุด (ข) ความคลาดเคลื่อนของสเกลเป็น % (ค) ความคลาดเคลื่อนสัมบูรณ์ของความกว้างเป็น มม. และ % แยกตามความกว้างอ้างอิง (ง) สัดส่วนที่อยู่ในช่วง ±10% · ผลใช้ **กำหนดช่วงเงื่อนไข (ระยะ มุม แสง) ที่วัดความกว้างได้เชื่อถือ** ซึ่งนำไปกำหนดกติกาค่าความมั่นใจใน 3.7.6 · ข้อจำกัด: crack scale ขอบคมกว่ารอยจริง จึงเทียบรอยจริงกับเกจเพิ่มเติมบางจุด

### 3.7 ประเมินสภาพสะพาน (ระดับ → EHI → T-BHI) — ส่วนที่เป็นผลงานหลัก

**3.7.1 จากลักษณะความเสียหายเป็นระดับ 0–5.** ใช้ระดับตามตารางที่ 2.3, ความกว้างรอยแบ่งระดับตามตาราง 2.4, กฎตัดสินจากภาพตามตาราง 2.6 · **ค่าที่ตกพอดีขอบเขตจัดเป็นระดับที่แย่กว่า** · ช่อง 0.23–0.25 มม. ของ PC จัดเป็นระดับ 2 · **เสาและหัวเสาใช้เกณฑ์ RC ส่วนคานหลักใช้เกณฑ์ PC** · BMMS ไม่ระบุตัวเลขของ "หลายจุด/บริเวณกว้าง" ผู้จัดทำกำหนดค่าตั้งต้น **≥ 3 จุดต่อชิ้นส่วนในภาพ หรือพื้นที่ประเภทนั้น ≥ 5% ของพื้นที่ชิ้นส่วน** และจะปรับร่วมกับวิศวกร · ชิ้นส่วนที่ไม่พบความเสียหาย = ระดับ 5 · **ระดับ 0 ไม่ถูกกำหนดจากภาพ**

**3.7.2 กฎความเสียหายซ้อนกัน.** พิกเซลที่ถูกครอบด้วย mask ความเสียหายมากกว่า 1 อัน นับเป็น **ระดับที่แย่ที่สุดเพียงระดับเดียว** เพื่อไม่นับซ้ำ · **พื้นที่ไม่เสียหาย = ระดับ 5 คำนวณจาก (พื้นที่ mask ชิ้นส่วน − พื้นที่รวมของ mask ความเสียหาย)** (ต้องนับ ไม่งั้นดัชนีต่ำเกินจริง)

**3.7.3 รวมผลหลายภาพ.** รวมที่ระดับ **สัดส่วน** ไม่บวกพิกเซลข้ามภาพ:

```
y_e,i(k) = A_e,i,k ÷ A_e,i            (3.1)  สัดส่วนพื้นที่ในภาพ i ที่ระดับ k
y_e(k)  = (1/N_e) × Σ_i y_e,i(k)      (3.2)  เฉลี่ยข้ามภาพที่มีชิ้นส่วน e
```

A_e,i = พื้นที่ mask ของชิ้นส่วน e ในภาพ i · A_e,i,k = ส่วนที่ระดับ k · N_e = จำนวนภาพที่ชิ้นส่วน e ปรากฏ · ภาพซ้อนกันอาจนับความเสียหายซ้ำ → ลดความซ้อนที่ต้นทาง (3.3.4) และทดสอบความไวโดยคำนวณซ้ำด้วยภาพที่คัดให้ห่างกัน · **กฎบังคับสถานะใช้การพบความเสียหายในภาพใดภาพหนึ่ง จึงไม่ได้รับผลจากการนับซ้ำ**

**3.7.4 EHI รายชิ้นส่วน.** คำนวณด้วยสมการ 2.1 โดยใช้ y_e(k) จากสมการ 3.2 และค่า C ตามตารางที่ 2.7 · ถ้าทั้งชิ้นส่วนอยู่ระดับเดียว EHI = 100 × C ของระดับนั้น · **รายงานระดับที่แย่ที่สุดของชิ้นส่วนควบคู่ EHI เสมอ**

**3.7.5 น้ำหนัก, q และ T-BHI.** คำนวณด้วยสมการ 2.2 · งานนี้ไม่มีแบบก่อสร้าง จึงใช้ **สัดส่วนพื้นที่ชิ้นส่วนที่ตรวจพบเป็นตัวแทนปริมาณ q:** `q_e = Σ_i (A_e,i ÷ G_i)` เมื่อ G_i = พื้นที่ทั้งภาพ i · น้ำหนัก W ตามตารางที่ 3 ของ Pellegrino: คานและเสา (รวมตอม่อ) 10 · หัวเสาและพื้น 9 · ราว 5 · คานทุกชนิดใช้ค่าของคานหลัก · ชิ้นส่วนที่ไม่ได้แบ่งส่วน (แผ่นรองรับ ฐานราก รอยต่อ) **ไม่อยู่ใน T-BHI** · ระบบรายงานรายการชิ้นส่วนที่พบและไม่พบทุกครั้ง และระบุ **"ไม่ครบชิ้นส่วนหลัก"** เมื่อไม่พบคาน เสา หรือหัวเสาชนิดใดเลย

**3.7.6 สถานะสะพาน กฎบังคับ และค่าความมั่นใจ.**
- **สถานะตามคะแนน T-BHI:** ดีมาก (100) · ดีพอใช้ (90 ถึง < 100) · พอใช้ (70 ถึง < 90) · ชำรุด (50 ถึง < 70) · วิกฤต (30 ถึง < 50) · วิบัติ (< 30) — ชื่อสถานะตาม BMMS ช่วงคะแนนผู้จัดทำกำหนด
- **กฎบังคับสถานะ:** เพราะดัชนีถูกเจือจางด้วยพื้นที่ หากพบความเสียหายระดับ 2, 1 หรือ 0 ในชิ้นส่วนหลัก (คาน เสา หัวเสา) สถานะสะพานต้อง **ไม่ดีกว่า** ชำรุด, วิกฤต หรือวิบัติ ตามลำดับ (ตามหลักค่าต่ำสุดของ BMMS) · ใช้การพบในภาพใดภาพหนึ่ง รวมระดับที่ได้จากตัวบ่งชี้ทางอ้อม โดยรายงานแยกว่ามาจากค่าความมั่นใจต่ำและแนะนำให้วิศวกรตรวจ
- **ค่าความมั่นใจ** (ตารางที่ 3.4) — ไม่เข้าสูตรคำนวณ แต่รายการค่าความมั่นใจต่ำถูกแนะนำให้ส่งตรวจละเอียด และรายงานมุมก้มเงยของกล้องด้วย:

| ค่าความมั่นใจ | เกณฑ์ | ตัวอย่าง |
|---|---|---|
| สูง | ระดับมาจากค่าที่วัดได้ตรงหรือสิ่งที่เห็นโดยตรง | ความกว้างรอย RC ที่มีสเกลและกว้างอย่างน้อย 3 pixel · เห็นเหล็กโผล่ชัดเจน |
| ปานกลาง | วัดได้เพียงบางส่วน | ความกว้างใกล้ 3 pixel · ภาพเฉียงมาก |
| ต่ำ | ต้องใช้ตัวบ่งชี้ทางอ้อม | ความลึกกะเทาะ · การเสียหน้าตัดของเหล็ก · รอยที่ไม่มีสเกลหรือ < 3 pixel · รอยคาน PC ที่ละเอียดเกินกว่าภาพโดรนแยกได้ |

### 3.8 เปรียบเทียบกับวิศวกรและผลที่คาดว่าจะได้รับ

นำผลระบบเทียบกับวิศวกรโยธาที่มีประสบการณ์ตรวจสะพานอย่างน้อย 1 ท่าน (ในเล่ม) ซึ่งประเมินระดับ 0–5 รายชิ้นส่วน **ประมาณ 15–20 ชิ้นส่วน** จากภาพชุดเดียวกัน **โดยไม่เห็นผลของระบบ** แล้วเทียบ **3 ชั้น:**
1. **การตรวจจับ/แบ่งส่วนของแต่ละแบบจำลอง** — วัดแยกเป็นขั้น
2. **ระดับรายชิ้นส่วน** — เทียบกับวิศวกรด้วยตารางสับสน (confusion matrix) และตรวจกฎแปลงด้วยชุดทดสอบหน่วย (unit test)
3. **T-BHI และสถานะ** — ตกช่องเดียวกับวิศวกรหรือไม่ และระบบให้สถานะดีกว่าวิศวกรหรือไม่ (พลาดไปทางอันตรายหรือเปล่า)

- [ ] **1.2, 1.3, 3.5 — แผนสำรองเรื่อง Qwen:** ตอนนี้ทั้งระบบฝากไว้กับ Qwen ถ้ารัน/ปรับแต่งไม่ได้ วัตถุประสงค์ข้อ 2, 4, 5 ต้องเดินต่อได้ → แยก "งานหลัก" (เดินจนจบโดยไม่พึ่ง Qwen) ออกจาก "ส่วนทดลอง" (Qwen เป็นตัวเปรียบเทียบ) พร้อมเขียนจุดตัดสินใจว่าจะทำต่อหรือหยุดตรงไหน
- [ ] **เครื่องที่ใช้:** Dell Precision 7865 (RAM 64 GB) + RTX 5070 Ti (VRAM 16 GB) — Qwen รุ่น 35B ใหญ่เกินจะปรับแต่งบนการ์ดนี้ → เลือกรุ่นที่รันได้บนเครื่องนี้และลองรันให้ได้เร็วที่สุด
- [ ] **ตาราง 2.9, หัวข้อ 2.2.3 และ 3.7.6:** ค่า C ของระดับ 4 และ 1 (0.83/0.17) ช่วงคะแนนสถานะ กฎบังคับสถานะ และระดับของค่าความมั่นใจ มาจากเอกสาร T-BHI ของโครงการ วช.69 → ให้อ้าง (ศุภศิษฏ์ ศรีวรานันท์ และคณะ, 2569ข) และแก้คอลัมน์สถานะในตาราง 2.9 ให้ตรงกัน
- [ ] **3.5.3:** ตอนนี้ใช้ผลชุดทดสอบ (3.8) ตัดสินว่าจะใช้กรอบจาก Qwen หรือ YOLO26 → ให้ย้ายไปตัดสินบน **ชุดตรวจสอบ (validation)** แล้วใช้ชุดทดสอบครั้งเดียวตอนรายงานผลสุดท้าย (ไม่งั้นผลจะดีเกินจริง เพราะใช้ชุดทดสอบไปแล้วในการเลือกโมเดล)
- [ ] **ตาราง 2.6 และ 3.7 — รอยที่วัดความกว้างไม่ได้:** การให้ "ระดับ 3 ตั้งต้น" ไม่ปลอดภัยจริง ใช้ได้เมื่อรอยแคบกว่าเกณฑ์ระดับ 3 จริง เช่น RC ถ่ายระยะใกล้ แต่ใช้กับคานอัดแรงไม่ได้ ตาราง 2.12 ของเราเองบอกว่าที่ 1 ม. วัดได้น้อยสุดราว 0.8 มม. ขณะที่ระดับ 2 ของคานอัดแรงเริ่มที่ 0.25 มม. รอยที่วัดไม่ได้จึงอาจเป็นระดับ 2 หรือ 1 อยู่แล้ว การให้ระดับ 3 ทำให้คานหลักดูดีกว่าจริงและกฎบังคับสถานะไม่ทำงาน ภาพที่ไม่มีสเกลก็เป็นแบบเดียวกัน → **แยกกรณีนี้ออกมา** ให้ผลระดับสะพานเป็น **"ยังตัดสินไม่ได้ ต้องส่งวิศวกรตรวจ"** และเขียนวัตถุประสงค์ข้อ 3 ให้ตรงกับชิ้นส่วนที่วัดได้จริง

### 7.3 เขียนเป็นแผนไว้ แล้วลงรายละเอียดหลังนำเสนอ

- **3.6.4 ทดสอบเลเซอร์:** ใต้สะพานควบคุมแสง/มุมได้ไม่ครบ → ทดสอบเต็มรูปแบบในที่ควบคุมได้ก่อน แล้วค่อยยืนยันใต้สะพานเฉพาะเงื่อนไขที่ใช้จริง และคิดถึงมุมลำแสงกับผิว (ถ้าลำแสงตกเฉียง จุดเลเซอร์ไม่เป็นจัตุรัสตามที่สมมติ)
- **รอยร้าวบนคานอัดแรง:** ลองดูการวัดบนภาพที่ตัดเฉพาะบริเวณความละเอียดเต็ม หรือกล้องเทเลของ Matrice 4E ช่วยได้แค่ไหน
- **3.3 และ 3.5.2 — ภาพสองชุดต่างกัน:** ชุดเดิมถ่ายไกล (สูง 20–40 ม.) ชุดใหม่ถ่ายใกล้ใต้สะพาน ขนาดรอยและมุมมองต่างมาก ถ้าฝึกด้วยชุดเดิมอย่างเดียวแล้วทดสอบกับชุดใหม่ ผลไม่ดีจะแยกไม่ได้ว่าเพราะโมเดลหรือเพราะภาพต่างชุด → นำบางรอบบินของชุดใหม่เข้าชุดฝึกด้วย และนับตัวอย่างแต่ละประเภทก่อนสรุปผลรายประเภท
- **3.7.3 และ 3.7.5 — EHI/T-BHI:** สูตรใช้ได้ตามเดิม ปัญหาอยู่ที่วิธีหาค่าป้อนจากภาพ ตอนนี้เฉลี่ยสัดส่วนข้ามภาพให้น้ำหนักเท่ากัน และใช้พื้นที่ชิ้นส่วนในภาพแทน q ผลจึงเปลี่ยนตามจำนวนภาพที่ถ่ายต่อชิ้นส่วน ทั้งที่สะพานเหมือนเดิม → หาวิธีที่ผลไม่ขึ้นกับจำนวนภาพ และให้ q มาจากปริมาณชิ้นส่วนจริงของสะพาน
- **3.8:** ให้ระบบออกผลในหน่วยเดียวกับที่วิศวกรประเมิน และเลือกชิ้นส่วนให้มีทั้งที่สภาพดีและเสียหายแล้ว เพื่อตอบได้ว่าระบบพลาดทางอันตรายหรือไม่

### 7.4 ตาราง 2.7 — ชื่อสถานะไม่ตรงชื่อระดับ (อาจารย์ให้เสนอ)

ถ้าชิ้นส่วนทั้งชิ้นอยู่ระดับ 4 (ดีพอใช้) EHI = 83 ซึ่งตามช่วงใน 3.7.6 (70 ถึง < 90) เป็นสถานะ **"พอใช้"** ไม่ใช่ "ดีพอใช้" ระดับอื่นก็เหมือนกัน: ระดับ 3 ได้ 67 = **"ชำรุด"** · ระดับ 2 ได้ 33 = **"วิกฤต"** ชื่อสถานะต่ำกว่าชื่อระดับเดิมหนึ่งขั้นทุกระดับ และ "ดีมาก" ต้องได้ 100 พอดี ถ้าระบบเจอความเสียหายเล็กน้อยแม้จุดเดียว สะพานจะไม่ได้สถานะนั้นเลย → **งานของเรา:** เสนอค่า C หรือช่วงคะแนนที่ทำให้ชิ้นส่วนระดับใดทั้งชิ้นได้สถานะชื่อเดียวกับระดับนั้น แล้วมาคุยกัน (ยังไม่ได้คำนวณ; ตัวเลขที่เสนอจะเป็นข้อเสนอของเรา ต้องให้อาจารย์เห็นชอบ)

> ถ้าสงสัยตรงไหน อาจารย์ให้คุยกันในกลุ่มหรือวันซ้อมนำเสนอ

## ส่วนที่ 8 — ค่าที่ผู้จัดทำกำหนดเอง (ต้องให้อาจารย์/วิศวกรเห็นชอบ) และเรื่องที่ยังรอตัดสิน

**ค่าที่เรากำหนดเอง:** C = 0.83/0.17 · ช่วงคะแนนสถานะ · กฎบังคับสถานะ · กฎตัดสินระดับจากภาพ (ตาราง 2.6) · นิยาม "หลายจุด" (≥ 3 จุด หรือ ≥ 5%) · ช่อง PC 0.23–0.25 มม. จัดเป็นระดับ 2 · ใช้สัดส่วนพื้นที่เป็น q · การจัดชิ้นส่วนสะพานไทยเข้ากลุ่ม W · ระยะ d ของเลเซอร์ (≥ 2 ค่า: 100 มม. และค่าที่มากกว่า) · ความซ้อนภาพเป้าหมาย ≤ 50% · สัดส่วน τ ของ 3.4.2 · อัตราส่วนแบ่งชุด 70:15:15

**ยังรอตัดสิน/ยืนยัน:** เสา/หัวเสาของสะพานเป็น RC หรือ PC · Qwen + SAM ใช้ได้ไหม (อาจารย์/วิศวกร) · ชั้นที่ 2 ของ 3.8 จะตรวจด้วย logic แบบไหน · ลำดับ 3.3.4 "คาน → … → คานยาว" คือคานเดียวกันหรือคนละแบบ · เกณฑ์คัดภาพ 3.4.1 หลังตัด GPS · ผังงาน 3.2 แบบทางการและสวย (ยังไม่เลือกเครื่องมือวาด) · แจ้งอาจารย์ว่าชื่อ 2.4/3.4 เปลี่ยนและตัด GSD

**ข้อควรจำ:** ความแม่นของโมเดลไม่ต้องสูงเลิศ (งาน Q1 ของ Çelik 2025 ได้ IoU เฉลี่ยเพียง 20.6%) ตัวชี้ขาดของงานนี้คือ "ตรวจพลาดจุดอันตรายไหม" และ "ระบบแปลงผลเป็นดัชนีที่ตรวจย้อนได้ไหม" ไม่ใช่ตัวเลข mAP สวย ๆ
