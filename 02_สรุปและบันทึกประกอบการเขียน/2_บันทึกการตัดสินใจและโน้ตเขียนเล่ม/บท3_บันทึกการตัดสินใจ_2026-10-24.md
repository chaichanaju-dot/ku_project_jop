# บท 3 — บันทึกการตัดสินใจของมะขาม (ระหว่างตรวจร่างโครง)

> จดตามที่มะขามสั่ง 2026-10-24 ยังไม่ได้ลงมือทำ — มะขามยังตรวจร่างโครงไม่จบ
> โครงฉบับล่าสุดอยู่ในแชท (ฉบับไม่มี 3 มิติ); เมื่อตรวจจบค่อยรวมเป็นไฟล์เดียว

## ตัดสินแล้ว
| หัวข้อ | การตัดสินใจ |
|---|---|
| 3.1 | ผ่าน (ใช้ตามร่างฉบับไม่มีโฟโตแกรมเมตรี) |
| 3.2 | ต้องการผังงานแบบ**เป็นทางการและสวย** (1 กล่อง = 1 หัวข้อ 3.3–3.8 ตามที่อาจารย์สั่ง) — **ยังไม่ได้เลือกเครื่องมือวาด** |
| 3.3.4 | เพิ่ม**ลำดับการเก็บภาพตามชิ้นส่วน**: คาน → หัวเสา → ตอม่อ → คานยาว → ขึ้นพื้นสะพาน (ถ้อยคำตามที่มะขามบอก — ดูข้อสงสัยด้านล่าง) |
| 3.4.1 | **ตัด GPS ทิ้ง** (error สูงมาก) — ไม่ใช้ GPS คัดหรือลดภาพซ้อน. (Gimbal pitch ที่ใช้ใน Confidence Flag อ่านจาก EXIF ไม่ใช่ GPS จึงไม่กระทบ) |
| 3.4 รวมภาพ | อยากหา**โปรแกรมที่รวมภาพได้โดยไม่ต้องสร้าง 3 มิติ** — มะขามอนุญาตให้ค้นในเน็ต |

## ข้อสงสัยที่ยังไม่ได้ถาม/ยังไม่ตัดสิน
- ลำดับใน 3.3.4: "คาน" ตัวแรกกับ "คานยาว" ตัวหลัง คือคานคนละแบบ (เช่น คานขวาง vs คานหลักตามยาว) หรือเป็นคานเดียวกัน — ต้องให้มะขามระบุก่อนเขียน
- เมื่อตัด GPS แล้ว 3.4.1 เหลือเกณฑ์คัดภาพแบบไหน (เบลอ/แสง/เห็นจุดเลเซอร์ และอาจลดซ้ำด้วยช่วงเวลาถ่าย) — รอมะขามตัดสิน
- การค้น "โปรแกรมรวมภาพแบบไม่ใช่ 3 มิติ" ยังไม่ได้ทำ (รอมะขามตรวจร่างจบก่อน); ถ้าค้น ต้องเปิดต้นฉบับยืนยันทุกรายการก่อนอ้างตามกติกา
- ขออนุมัติอาจารย์เปลี่ยนชื่อ 2.4 และ 3.4 (ดูหัวไฟล์ proposal_คัดเปเปอร์)
