## 1. รายงานต่อเปเปอร์

### [19] Crack Identification for Bridge Structures Using an Unmanned Aerial Vehicle (UAV) Incorporating Image Geometric Correction — Li, J.; Li, X.; Liu, K.; Yao, Z. (2022) — Buildings 12(11):1869, doi:10.3390/buildings12111869 (p.1)
- ชนิด: เปเปอร์วิจัย (MDPI, open access) ; อายุ: 2022 (ผ่านมา ~4 ปี อยู่ในช่วง 5-10 ปี)
- **วัตถุประสงค์ (p.1–2)**: วัดความกว้างรอยร้าวสะพานจากภาพ UAV โดยแก้ perspective distortion ด้วยเลเซอร์ขนาน 4 จุดวางเป็นสี่เหลี่ยมจัตุรัส
- **วิธีการ**:
  - อุปกรณ์ (p.3): quadrotor ออกแบบเอง ; กล้อง zoom 48 ล้านพิกเซล ; **เลเซอร์ขนาน 4 ตัว กำลัง 50 mW** ("50 MW" ในต้นฉบับ น่าจะพิมพ์ผิด) บนโครงเดียวกับกล้อง ; ultrasonic US-100 วัดระยะถ่าย (และถ้า <500 มม. ให้ลอยนิ่งกันชน) ; แบตเตอรี่ 2×3500 mAh บินได้ ~35 นาที (p.3, p.12–13)
  - **ระยะห่างจุดเลเซอร์ข้างเคียง d = 100 มม.** (p.9 "the distance between the centers of the adjacent laser points was 100 mm")
  - **หาจุดเลเซอร์ในภาพ (p.6)**: ใช้ grayscale thresholding + red component detection แล้วหาจุดศูนย์กลางมวล (centroid) ของบริเวณเล็กๆ เป็นพิกัด (u_i, v_i)
  - **แก้ perspective (p.5–6, Eq. 1–6)**: แปลงสี่เหลี่ยมคางหมู O1–O4 → สี่เหลี่ยมจัตุรัสขอบยาว a (C1–C4) ด้วย "linear correction algorithm" ; ค่าสัมประสิทธิ์ a11..a32 หาจากสมการ simultaneous ; **สมการ (6) ตั้ง a31 = 0, a32 = 0** (p.6) — ผู้รายงานสังเกตว่านี่คือรูปแบบ affine ไม่ใช่ projective homography เต็ม (ซึ่ง a31, a32 ≠ 0) ; เปเปอร์ไม่ได้เรียกว่า homography ตรงๆ (เรียก "linear correction", "four-point linear correction algorithm" p.1, 5) — **ถ้าจะอ้างว่าเป็น homography ต้องระวัง; ยืนยันไม่ได้ว่าคุณสมบัติแก้ perspective แบบ convergent ครบถ้วน**
  - Method 1 (เลเซอร์) (p.9, Eq. 11–12): µ = a/D (พิกเซลต่อมม. = ระยะพิกเซลระหว่างจุดเลเซอร์หลังแก้ ÷ ระยะจริง D) ; α2 = α1/µ
  - Method 2 (lens imaging) (p.9, Eq. 13–14): L2 = L1·f/(L1−f) ; **α2 = ((L1 − f)/f)·α1** โดย L1 = ระยะจาก ultrasonic, f = ความยาวโฟกัส — คือสูตรเทียบเท่า GSD แบบไม่มี perspective correction ในสมการ
  - ภาพ: gray linear stretch (Eq. 7) → Otsu (Eq. 8–9, p.8) → median filter → **LoG edge (Eq. 10, p.9)** → ความกว้าง = ระยะสั้นสุดระหว่างขอบ (Eq. 15–16, p.10)
- **ผลที่สำคัญ (p.10–12, Table 1 p.12)**: เทียบกับ "high-precision width measurements" (หน้าจอดิจิทัล, Fig. 12 — ไม่ระบุรุ่น/ความละเอียดเครื่องวัดในข้อความ) 12 รอย กว้าง 0.16–0.66 มม., ระยะถ่าย 501–720 มม.
  - Method 1: อัตราส่วนเฉลี่ย **0.97**, SD **0.07**, CV **7.59%** (p.11 ; คำนวณใหม่ได้ mean 0.967, SD 0.073, CV 7.59% ตรง)
  - Method 2: อัตราส่วนเฉลี่ย **1.15**, SD **0.18**, CV **15.73%** (p.11 ; คำนวณใหม่ได้ mean 1.146, SD 0.183, CV 15.98% — ต่างในทศนิยมเพราะปัดเศษตาราง)
  - **คำนวณใหม่เอง (จาก Table 1)**: ความคลาดเคลื่อนสัมบูรณ์ Method 1 = −0.04 ถึง +0.02 มม. เฉลี่ยสัมบูรณ์ **0.021 มม.** ; Method 2 เฉลี่ยสัมบูรณ์ **0.070 มม.** สูงสุด 0.17 มม. (รอย 7) ; **ความคลาดเคลื่อนสัมพัทธ์สัมบูรณ์เฉลี่ย Method 1 = 6.6%**, Method 2 = 18.1%
  - นอกช่วง ±10%: Method 1 = **4/12** (รอย 1, 5, 8, 11) ; Method 2 = **7/12** (รอย 2, 4, 6, 7, 8, 11, 12 : 1.43, 1.28, 1.12, 1.31, 1.13, 1.31, 1.34) ; นอก ±5%: Method 1 = 6/12, Method 2 = 10/12
  - **คำกล่าว "measurement accuracy of over 95%" (abstract, p.1)**: ตรวจแล้ว **ไม่ได้จากตาราง** — ได้ ~96.7% ก็ต่อเมื่อใช้ค่าเฉลี่ยของอัตราส่วนที่มีเครื่องหมาย (ค่าบวกลบหักล้างกัน) ; ถ้าใช้ความคลาดเคลื่อนสัมบูรณ์เฉลี่ย = 93.4%
- **ความเกี่ยวข้องกับงานเรา**: **ใช้แน่** — เป็นงานเดียวในกลุ่มที่เทียบ "เลเซอร์จุดในภาพ + d ที่ทราบ" กับ "สเกลจากระยะ+focal length (แบบ GSD)" ด้วยภาพชุดเดียวกัน → รองรับ 2.5 (perspective, เลเซอร์) และ 3.6 (เทียบวิธี). ใกล้กับแผนของเรามากสุด (เลเซอร์ขนาน 4 จุด ระยะห่างทราบ มองเห็นเป็นจุดในภาพ)
- **ข้อเท็จจริงที่หยิบไปเขียนได้เลย**:
  - เลเซอร์ขนาน 4 ตัวเรียงเป็นสี่เหลี่ยมจัตุรัส d = 100 มม. บนโครงกล้อง (p.3, p.9)
  - หาจุดเลเซอร์ด้วย threshold + องค์ประกอบสีแดง แล้ว centroid (p.6)
  - แปลงสี่เหลี่ยมคางหมู→จัตุรัส ได้อัตราพิกเซล µ = a/D (p.5–6, p.9)
  - ที่ระยะ 0.50–0.72 ม. (Table 1, p.12) Method 1 อัตราส่วนเฉลี่ย 0.97 (CV 7.59%) vs Method 2 1.15 (CV 15.73%) (p.11)
  - ผู้เขียนยอมรับว่าต้องดัดแปลง UAV ติดเลเซอร์ที่เลนส์ (p.13) และแนะให้หาวิธีแก้ที่ปฏิบัติจริงกว่า เช่น AI (p.13)
- **ข้อจำกัด / ห้ามอ้างเกินจริง**:
  - ระยะทดสอบแคบ 0.50–0.72 ม. เท่านั้น ; ไม่รายงานมุมถ่าย (องศา) ของ 12 ภาพ ; **ไม่รายงานแสง/เวลาถ่าย** (บอกแค่เลเซอร์ 50 mW "suitable for bright sunlight", p.5 เป็นคำกล่าวไม่ใช่การวัด) ; ไม่รายงานขนาดพิกเซล/GSD
  - เปรียบเทียบ Method 1 vs 2 **มีตัวแปรปนกัน**: Method 1 แก้ perspective ด้วยเลเซอร์ ส่วน Method 2 ไม่มีการแก้มุมในสมการ และ **ยืนยันไม่ได้ว่า α1 ใน Method 2 วัดจากภาพก่อนหรือหลังแก้ ไม่ระบุขนาดพิกเซลที่ใช้แปลง α1 เป็นมม.บนเซนเซอร์ ไม่ระบุความแม่นของ ultrasonic** — จึงสรุปไม่ได้ว่า "เลเซอร์ดีกว่า GSD" เพราะตัวเลเซอร์เอง หรือเพราะการแก้ perspective ต่างหาก
  - n = 12 รอย สะพานเดียว เลือกจุดที่เข้าถึงง่าย ; ไม่มีการทดสอบรอยโค้ง/พื้นผิวไม่เรียบ (แม้ Fig. 4b,c พูดถึง) ; ตารางไม่รายงานค่าซ้ำ
  - Data availability "Not available" (p.14)

(p.6)

## 3. หลักฐานรองรับหัวข้อ 3.6 (เทียบ 3 วิธี: เลเซอร์+GSD / เลเซอร์อย่างเดียว / GSD อย่างเดียว โดยใช้ crack scale เป็นอ้างอิง)

**สถานะตรงๆ: ไม่มีเปเปอร์ใดในกลุ่มนี้เทียบครบทั้ง 3 วิธี**
- **เลเซอร์อย่างเดียว vs GSD(แบบระยะ+focal) อย่างเดียว**: มีเฉพาะ **Li 2022** (Method 1 เทียบ Method 2 ภาพชุดเดียวกัน 12 รอย ที่ 0.50–0.72 ม., p.11–12) — แต่ตัวแปรปนกันเรื่อง perspective (ดูข้อจำกัดในรายงาน [19])
- **เลเซอร์+GSD**: ใกล้สุดคือ **Peng 2021** (ระยะจากเลเซอร์ + GSD จาก intrinsics + cosθ) แต่ไม่มีวิธีอื่นมาเทียบ ; **Zhang 2026** ใช้เลเซอร์วัดระยะ + homography (ไม่มี GSD ในสมการ) และอ้างว่า GSD เดี่ยวมี systematic bias (p.2–3) โดยไม่ได้ทดลองเทียบ
- **crack scale / ป้ายความกว้างอ้างอิง**: **Zhang 2026** ใช้ป้ายแถบรับรอง 0.8–20 มม. เป็นค่าอ้างอิงที่ 2/4/6 ม. × 0°/45° (p.19–20) — เป็นแบบอย่างของวิธีทดสอบ ; ที่เหลือใช้เวอร์เนียร์/เกจดิจิทัล/ผู้ตรวจ ; **ไม่มีเปเปอร์ใดนำป้ายอ้างอิงมาเทียบ 3 วิธีสเกล**
- ข้อสังเกตเพื่อออกแบบ 3.6 (ข้อเสนอของผู้รายงาน ไม่ใช่ข้อความในเปเปอร์): (ก) ใช้ป้ายความกว้างรับรองเป็นตัวตัดสิน และรายงานความผิดพลาดเป็น "มม. และ % แยกตามความกว้างป้าย" ไม่ใช่ค่าเฉลี่ยมีเครื่องหมายเดียว (ดู Li, Liu ว่าค่าเฉลี่ยมีเครื่องหมายบังความจริง) ; (ข) กำหนดเกณฑ์ "ความกว้างต่ำสุดที่เชื่อได้" = n×GSD (Liu: n = 3 เป็นขอบการตรวจพบ, >7 พิกเซลจึงมีโอกาส <10%) เพื่อทำ Confidence Flag ; (ค) เปรียบเทียบที่หลายระยะ (อย่างน้อย 2/4/6 ม. ตาม Zhang) และ 0°/45°

## 4. สรุปกลุ่ม (G5)
- **ควรเข้า proposal**: **[18] Zhang 2026, [21] Zuo 2026, [33] Liu 2020 (ซึ่งอยู่ใน "paper ที่ใช้" แล้ว — บทบาทตรงแค่ส่วนหนึ่ง)** + **เสนอเพิ่ม [19] Li 2022** (งานเดียวที่ตรงกับเลเซอร์ขนาน 4 จุด d ทราบ และเทียบกับสเกลแบบ GSD) + **[20] Peng 2021** (แหล่งสูตร GSD ที่มีตัวแปรครบ + ระยะจากเลเซอร์)
- **บทบาทของ [33] Liu 2020**: **ไม่ตรงกับวิธีเลเซอร์/homography ของ 3.6** — ตรงกับ 2.4 (SfM+mesh+overlap) และ 2.5 (อธิบาย perspective distortion, thin-lens, เกณฑ์ 3 พิกเซล/>7 พิกเซล) ; ควรอ้างในบทบาทนั้น ไม่ใช่เป็นหลักฐานของเลเซอร์
- **ตัด/ระวัง**: ส่วน R-FCN/Haar-AdaBoost ใน [20] และ CrackMamba-Net ใน [18] ไม่ตรงกับ YOLO-seg/Qwen/SAM ของเรา (ใช้เฉพาะส่วนสเกล) ; [21] ห้ามอ้างว่า "แม่นยำ" (วัดความซ้ำ ไม่ใช่ความถูกต้อง)
- **จุดที่ต้องบันทึกในเล่มตรงๆ**: Li 2022 ทดสอบเพียง 0.50–0.72 ม. n=12 ; Zuo 2026 รอย <0.3 มม. ถูกวัดเกินเฉลี่ย 2.5× (15/15 รอยจัดสถานะ CS ผิด) — สาเหตุที่เปเปอร์เสนอ (การแบ่งส่วน) ยังเป็นสมมติฐาน ; Liu 2020 รอย 0.45 มม. ที่ 1.03 ม. วัดเกิน +249%
- **ช่องว่างที่เปเปอร์กลุ่มนี้ไม่ปิด**: (1) ไม่มีงานทดสอบ >6 ม. กับรอยร้าวจริง และไม่มีการทดสอบใต้สะพานไกล (>~3 ม. บนรอยจริง) ; (2) ไม่มีใครเทียบ 3 วิธีสเกลพร้อมกัน ; (3) ไม่มีใครรายงานแสง (lux/เวลา) เป็นตัวเลข ; (4) ไม่มีงานใช้ SAM/YOLO-seg กับสเกลเลเซอร์ ; (5) ไม่มีงานที่ทดสอบรอยบาง <0.3 มม. ที่ระยะ >1 ม. จนสำเร็จ ; (6) ไม่มีงานกับ PC I-girder ท้องคานโดยตรง (Peng ใกล้สุด: ท้องพื้น hollow slab) ; (7) การอ้างอิงสูตร cosθ ของ Peng (Eq. 2) ยังต้องให้ผู้รู้ตรวจ (ดูหัวข้อ [20])
