### [05] โครงการศึกษาและพัฒนาระบบการบริหารงานบำรุงรักษาสะพาน — คู่มือการสำรวจและตรวจสอบสะพาน — กรมทางหลวง (ผู้จัดทำตามเมทาดาตาไฟล์ = IMMS GROUP) — ราว พ.ศ. 2555

- ชนิด: คู่มือ/มาตรฐานปฏิบัติของหน่วยงานรัฐ (ไม่ใช่เปเปอร์วิจัย). อายุ: ข้อความอ้างข้อมูลปี "สำนักวิจัยและพัฒนางานทาง, 2555" (PDF p.14 คำนำ, p.16) ; เมทาดาตา PDF สร้าง 2012-12-06 → อายุ ~14 ปี (เกินช่วง 5-10 ปีของไกด์ไลน์ แต่เป็นมาตรฐานที่หน่วยงานใช้จริง ไม่ใช่งานวิจัย — ควรระบุปีให้ตรง). **ปีพิมพ์ที่แน่ชัดและชื่อผู้จัดทำบนหน้าปก ยืนยันไม่ได้** (หน้า 1 เป็นภาพไม่มีข้อความ ; ปี 2555 ได้จากข้อความอ้างอิงภายใน + เมทาดาตา ; ชื่อ IMMS GROUP มาจากเมทาดาตา และคำนำ p.14 ขอบคุณ "บริษัท ไอเอ็มเอ็มเอส จำกัด")
- ขอบเขตตามที่เอกสารระบุเอง (PDF p.16, ข้อ 1.1-1.2): จัดทำจาก "ความเสียหายที่สามารถมองเห็นได้ด้วยสายตา" เพื่อ "ประเมินลักษณะสภาพการใช้งานของระบบโครงสร้างสะพานเบื้องต้น" ; ครอบคลุม "สะพานคอนกรีต และสะพานโครงสร้างประกอบ ไม่รวมสะพานขึง" ; "มุ่งเน้นเฉพาะการตรวจสอบโครงสร้างสะพานด้วยสายตา"
- โครงสร้างเล่ม (สารบัญ PDF p.2-12): บท1 บทนำ · บท2 โครงสร้างและองค์ประกอบสะพาน (รวม I-Girder 2.1.2, องค์ประกอบ 2.2) · บท3 การสำรวจและตรวจสอบ (3.5 = routine/principal/special) · บท4 ประเภทความเสียหายและเกณฑ์จัดลำดับ ชิ้นส่วนละ 1 หัวข้อ (4.1 Deck ... 4.20 Slope Protection) · บท5 การประเมินผล · บท6 สรุป
- **ไม่พบเรื่องโดรน/UAV/ภาพถ่ายทางอากาศ/ดัชนีสุขภาพ (health index)/น้ำหนักชิ้นส่วน (weight) ในเล่ม** (ค้นด้วยคำเหล่านี้แล้ว ไม่มีผลที่เกี่ยวข้อง) — เป็นการตรวจด้วยสายตาโดยคนทั้งหมด

### (3) เกณฑ์ spalling / exposed rebar / honeycomb / efflorescence / rust stain ต่อระดับ
นิยามชนิดความเสียหายคอนกรีต (ข้อ 4.1.1, PDF p.99-108, พิมพ์ 4-2…4-11): รอยแตก (Cracking) · การหลุดแซะ (Scaling) · การหลุดแยกเป็นแผ่น (Delamination) · การหลุดล่อน (Spalling) · การเกิดขี้เกลือ (Efflorescence) · รูพรุนรังผึ้ง (Honeycomb) · Pop-Out · การสึกหรอ (Wear) · ถูกชน (Collision) · สึกกร่อน (Abrasion) · บรรทุกเกิน (Overload) · เหล็กเสริมเป็นสนิม (Reinforcing Steel Corrosion) · การเสื่อมของคอนกรีตอัดแรง (PC Deterioration)

ตัวเลขนิยามเชิงปริมาณที่มีในเนื้อความ (ไม่ใช่ในตารางระดับ):
- Scaling 4 ขนาด (PDF p.100, 4-3): เบา = สูญเสียถึงลึก 6 มม. ; กลาง = 6 มม.–1.2 ซม. ; รุนแรง = 1.2–2.5 ซม. ; รุนแรงมาก = >2.5 ซม. "และเหล็กเสริมในคอนกรีตโผล่ออกมาให้เห็น (Exposed)"
- Spalling (PDF p.104, 4-7): ขนาดเล็ก = ลึก <2.5 ซม. หรือ เส้นผ่านศูนย์กลางประมาณ 15 ซม. ; ขนาดใหญ่ = ลึก >2.5 ซม. หรือ >15 ซม. ; "ส่วนใหญ่แล้วเมื่อมีการหลุดล่อนจะสามารถเห็นเหล็กเสริมได้"
- Delamination (PDF p.103, 4-6): ตรวจด้วยการเคาะฟังเสียงค้อน (โพรงใต้ผิว) ; สาเหตุหลักคือเหล็กเสริมเป็นสนิมขยายตัว (สนิม "มากถึง 10 เท่าของปริมาตรเหล็กเสริม")
- Efflorescence (PDF p.105, 4-8): คราบสีขาว ตกผลึกเกลือ "เป็นตัวบ่งชี้ว่าคอนกรีต ณ ที่นั้นได้ถูกปนเปื้อนแล้ว"
- Honeycomb (PDF p.105): ช่องว่างในเนื้อคอนกรีตจากการจี้ไม่เหมาะสม มวลรวมหยาบแยกตัว
- รอยเปื้อนสนิม (Rust stain): มีเพียงข้อความ "รอยเปื้อนจากสนิม และการเกิดขี้เกลือ มักจะปรากฏให้เห็นตามรอยแตกต่างๆ" (PDF p.99, 4-2) — **ไม่มีเกณฑ์ระดับแยกสำหรับ rust stain ; ไม่มีเกณฑ์ระดับแยกสำหรับ efflorescence เป็นพื้นที่/ขนาด**

### (4) ค่า W: คานหลัก/เสา/กำแพงตอม่อ 10 · หัวเสา/พื้น/แผ่นรองรับ 9 · ตอม่อริม/แผ่นพื้นคอสะพาน 8 · ฐานราก 7 · รอยต่อ/ผิวทาง 6 · ราวกันตก 5 — ตรงกับ BMMS ไหม
**ไม่ตรง — ไม่พบค่าถ่วงน้ำหนักชิ้นส่วน (component weight) ใดๆ ใน BMMS เลย** (ค้นคำ weight / ค่าถ่วง / ตัวคูณ / คะแนน / ดัชนี / Health Index / BHI ทั้งไฟล์ ไม่พบการให้น้ำหนัก ; ที่เจอเป็นการ "ให้คะแนน" ระดับ 0-5 เท่านั้น เช่น PDF p.78). สิ่งที่ BMMS มีที่เกี่ยวข้อง:
- แบ่งชิ้นส่วนเป็น 3 กลุ่ม: โครงสร้างส่วนบน (พื้น/Deck, คานตามยาว/Girder, ค้ำยันคาน/Diaphragm), ส่วนล่าง (คานรัดหัวเสา, ค้ำยันตอม่อ, เสาตอม่อ, กำแพงตอม่อ, ฐานราก, เสาเข็ม), ส่วนประกอบรอง (Secondary Components เช่นราว ผิวทาง รอยต่อ ระบายน้ำ) (PDF p.36-39, พิมพ์ 2-7…2-10) ; เรียกส่วนบนว่า "องค์ประกอบหลักของสะพาน" (PDF p.36) — เป็นการจัดกลุ่มบทบาท ไม่ใช่ตัวเลขน้ำหนัก
- Table 4-1 (PDF p.98-99) แยก "โครงสร้างส่วนที่รับแรงหรือส่วนที่สำคัญ" กับ "ส่วนที่ไม่รับแรงหรือไม่สำคัญ" เป็นข้อความเชิงคุณภาพ ไม่มีสัดส่วน
- **วิธีรวมคะแนนเป็นสะพานใน BMMS = ค่าต่ำสุด (worst-governs) ไม่ใช่ถ่วงน้ำหนัก**: PDF p.78 (3-31) "เลือกคะแนนที่มีค่าน้อยที่สุดเป็นตัวระบุสภาพโดยรวมของชิ้นส่วนหลักของสะพาน" ; PDF p.96 (3-49): (ก) ใช้ระดับที่แย่ที่สุดเป็นตัวแทนของประเภทชิ้นส่วนในแต่ละบริเวณ (ข) ใช้ระดับของชิ้นส่วนที่แย่ที่สุดเป็นตัวแทนของแต่ละกลุ่ม 3 กลุ่ม (ค) **"ใช้ค่าต่ำสุดของกลุ่มโครงสร้างส่วนบนและโครงสร้างส่วนล่างเป็นตัวแทนระดับสภาพการใช้งานโดยรวมของสะพาน"** (ส่วนประกอบรองไม่เข้าสูตรโดยรวม) — ตัวอย่างคำนวณ PDF p.370 (5-11): บน=4, ล่าง=3, รอง=1 → Overall Condition Rating = 3 ; ตัวอย่างห้วยคุ PDF p.362-363: บน 0 ล่าง 0 รอง 2 → โดยรวม 0
- ผลคือ **สูตร T-BHI = Σ(q·W·EHI)/Σ(q·W) และตาราง W ของเรา ไม่มีพื้นฐานใน BMMS** — ต้องมีที่มาจากแหล่งอื่น (เช่น AASHTO/NBI/JSCE ในเอกสาร 04/07/09 ซึ่งอยู่นอกงานฉบับนี้) หรือเป็นข้อเสนอสังเคราะห์ของนิสิต แล้วต้องเขียนว่าเป็นข้อเสนอของงานนี้ ไม่อ้างว่ามาจาก BMMS

### (5) นิยามระดับ 5-0 ตรงกับ ดีมาก/ดีพอใช้/พอใช้/ชำรุด/วิกฤต/วิบัติ ไหม ; 'กฎบังคับสถานะ' มีพื้นฐานใน BMMS ไหม
**นิยามระดับ: ตรงทุกคำ** — Table 4-1 "เกณฑ์การจัดลำดับความเสียหายโครงสร้างสะพานของกรมทางหลวง" (PDF p.98-99, พิมพ์ 4-1…4-2): 5=ดีมาก ("สภาพโครงสร้างดี หรือใหม่") · 4=ดีพอใช้ ("สภาพพอใช้ในเกณฑ์ดี ; ส่วนที่รับแรง/สำคัญ อยู่ในเกณฑ์ดี พิจารณาซ่อมบำรุงปกติ ; ส่วนที่ไม่รับแรง/ไม่สำคัญ พอใช้ พิจารณาซ่อมบำรุงตามกำหนดเวลา") · 3=พอใช้ ("สภาพพอใช้ที่ต้องพิจารณาซ่อมบำรุงตามกำหนดเวลา") · 2=ชำรุด ("สภาพชำรุดที่ต้องพิจารณาซ่อมแซมหรือการบำรุงพิเศษ ; ส่วนที่รับแรง/สำคัญ ชำรุดที่ต้องพิจารณาซ่อมแซมหรือบำรุงพิเศษ ; ส่วนที่ไม่รับแรงต้องซ่อมแซมให้กลับคืนสู่สภาพเดิม") · 1=วิกฤต ("สภาพชำรุดที่ต้องพิจารณาซ่อมแซมอย่างเร่งด่วนหรือต้องทำการบูรณะ ; ส่วนที่รับแรง/สำคัญ เสียหายมากต้องซ่อมแซมอย่างเร่งด่วนหรือบูรณะ") · 0=วิบัติ ("สภาพชำรุดเสียหายมาก ต้องทุบสะพานทิ้งและก่อสร้างใหม่"). ระดับ 4-0 นิยามด้วยการซ่อมบำรุง ไม่ใช่ตัวเลขความเสียหาย.

**"กฎบังคับสถานะ"**: ไฟล์บริบทไม่ได้นิยามกฎนี้ ผมตีความว่า "เงื่อนไขที่บังคับให้สถานะสะพานต่ำกว่าที่คำนวณจากสูตรได้" — สิ่งที่ BMMS มีที่ใกล้เคียง (ไม่ใช่กฎแบบเดียวกัน):
 - กฎ worst-governs ข้างต้น (PDF p.78, 96) — ชิ้นส่วนเลวสุดของกลุ่มกำหนดกลุ่ม ; บน/ล่างที่ต่ำสุดกำหนดโดยรวม → บังคับสถานะในทางปฏิบัติ
 - เกณฑ์ระดับ 1 ที่ "รอยแตกเนื่องจากแรงเฉือน/แรงดัดที่มีผลต่อกำลัง — รอยแตกทุกขนาด", เห็นลวดอัดแรงเป็นจำนวนมาก, แอ่นตัวผิดปกติ (PDF p.111, 137) = ชนิดความเสียหายที่ลงระดับ 1 โดยไม่คำนึงความกว้าง
 - การยกระดับการตรวจ: ผู้ตรวจปกติ "พิจารณาว่าจำเป็นต้องขอการตรวจสอบเพิ่มเติมหรือไม่" ขอตรวจหลักเมื่อ "สะพานมีความเสียหายค่อนข้างมาก" ขอตรวจพิเศษเมื่อ "เสาตอม่อเอียง เสาตอม่อเคลื่อนตัวมากเกินไป หรือฉุกเฉิน เช่น เกิดอุบัติเหตุทำให้สะพานบางส่วนพังหรือเสียหายอย่างรุนแรง" (PDF p.90, 3-43) ; ผู้ตรวจหลักขอตรวจพิเศษได้ (PDF p.96)
 - **ไม่พบกฎเชิงตัวเลขแบบ "ถ้ามีชิ้นส่วนหลักระดับ ≤ X ให้สถานะสะพานไม่ดีกว่า Y" ที่ผูกกับดัชนี 0-100** — ถ้าแผนเรามีกฎลักษณะนั้น ฐานจริงที่อ้างได้คือ worst-governs (min) เป็นหลักการ แต่ต้องอ้างว่า BMMS ใช้ค่าต่ำสุด ไม่อ้างว่า BMMS มี threshold ของเรา

## ความเกี่ยวข้องกับงานเรา
- ระดับ: **ใช้แน่** (แหล่งเกณฑ์ระดับสภาพ 0-5 ของไทยตัวหลัก) → 2.2 (การตรวจสอบ เกณฑ์ประเมินสภาพ) ; 2.1 (ประเภท/องค์ประกอบ/ความเสียหาย: บท 2 + ข้อ 4.1.1) ; รองรับ 3.7 (ระดับ → EHI → T-BHI) ในส่วน "ระดับ 0-5 และชื่อสถานะ" และ 3.3 (ชนิดชิ้นส่วน I-Girder, การแบ่งส่วน/รหัสชิ้นส่วน ข้อ 3.4 PDF p.79-87)
- **ใช้ได้เลย:** ตารางระดับ 5-0 + ชื่อสถานะ (Table 4-1) ; เกณฑ์รอยร้าว RC และ PC ต่อระดับ ; นิยามชนิดความเสียหาย (spalling/scaling/delamination/efflorescence/honeycomb/corrosion) ; ประเภทการตรวจ routine/principal/special + ความถี่ + ทักษะผู้ตรวจ (สนับสนุนว่างานเราเป็นการคัดกรองก่อนการตรวจหลัก/ปกติ ไม่ใช่ special) ; หลักรวมแบบ worst-governs
- **ใช้ไม่ได้/ห้ามอ้าง:** ค่า W ทั้งชุด · สูตร EHI/C_hi (5=1.00…0=0) · T-BHI ถ่วงน้ำหนักด้วยพื้นที่ q — ไม่มีใน BMMS (BMMS ให้เลขระดับจำนวนเต็มต่อชิ้นส่วน ไม่มีสัดส่วนพื้นที่ในแต่ละระดับ) ; ไม่มีเกณฑ์ spalling/honeycomb/efflorescence/rust stain เป็นพื้นที่ (m² หรือ %) — BMMS ใช้ถ้อยคำ "เล็กน้อย/หลายจุด/บริเวณกว้าง" ไม่ให้ตัวเลขพื้นที่ ดังนั้นการแปลงเป็นเกณฑ์วัดจากภาพ (เช่น % พื้นที่) เป็นข้อเสนอสังเคราะห์ของงานเรา ต้องหาที่มาอื่นหรือระบุว่าตั้งเอง
- ข้อสังเกตที่ขัดกับแผน: (ก) BMMS ให้ระดับต่อชิ้นส่วนด้วยการตัดสินของผู้ตรวจ ไม่ใช่การเฉลี่ยตามพื้นที่ ; (ข) ดัชนีรวมของ BMMS คือ min ไม่ใช่ผลรวมถ่วงน้ำหนัก ; (ค) ตารางคาน (4-5) ตัดค่า RC ระดับ 2/1 เหลือ PC อย่างเดียว ตรงกับ PC I-Girder ของเรา ; (ง) ตัวเลข PC มีช่องว่าง 0.23-0.25 ; (จ) ระดับ 2-1 ผูกกับ "รอยแตกที่เกิดจากเหล็กเสริมเป็นสนิม/เห็นลวดอัดแรง/รอยเฉือน-ดัดที่กระทบกำลัง" ไม่ได้ดูความกว้างอย่างเดียว — วัดความกว้างจากโดรนอย่างเดียวจึงไม่ครอบคลุมเกณฑ์เต็มของ BMMS
