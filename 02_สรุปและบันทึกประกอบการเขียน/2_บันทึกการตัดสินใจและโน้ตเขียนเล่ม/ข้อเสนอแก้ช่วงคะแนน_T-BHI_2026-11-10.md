# ข้อเสนอแก้ "ช่วงคะแนนสถานะ" ของ T-BHI (ตาราง 2.7 และหัวข้อ 3.7.6)

> **สถานะ:** ข้อเสนอสำหรับคุยในทีมและกับอาจารย์ **ยังไม่ผ่านทีม ยังไม่ผ่านอาจารย์ ห้ามลงเล่มจนกว่าจะตกลง**
> **ผู้เขียน:** Claude · 10 พ.ย. 2569 (เขียนใหม่ให้อ่านง่าย ตัวเลขเหมือนฉบับแรกทุกตัว)
> **ตัวเลขในส่วนที่ 5–6** ผู้จัดทำคำนวณด้วย Python จากสูตร EHI ของเล่ม (สมการ 2.1) ไม่ใช่ผลจากภาพจริง
> **เอกสารต้นฉบับที่เปิดตรวจแล้ว:** `03_เปเปอร์งานวิจัย/2_เกณฑ์ตรวจสอบสะพาน/0_[อ่านก่อน] เกณฑ์ประเมิน T-BHI (สังเคราะห์ล่าสุด).pdf` (เรียกต่อไปว่า "เอกสาร T-BHI") หน้า PDF 53, 55, 56, 57 · ความเห็นอาจารย์ 30 ต.ค. ส่วนที่ 3 · ข้อเสนอ ก/ข ตามตาราง 2.7 ในเล่ม v11

## คำที่ใช้ในไฟล์นี้

| คำ | ความหมายแบบง่าย |
|---|---|
| **ระดับ (0–5)** | คะแนนสภาพของความเสียหายตามคู่มือ BMMS: 5 ดีมาก · 4 ดีพอใช้ · 3 พอใช้ · 2 ชำรุด · 1 วิกฤต · 0 วิบัติ |
| **ค่า C** | ตัวคูณของแต่ละระดับ ใช้แปลงระดับเป็นคะแนน เช่น ระดับ 4 → 0.83 |
| **EHI** | คะแนนเต็ม 100 ของชิ้นส่วนชนิดหนึ่ง = 100 × (ค่า C ของแต่ละระดับ × สัดส่วนพื้นที่ที่อยู่ระดับนั้น) รวมกัน |
| **T-BHI** | คะแนนเต็ม 100 ของทั้งสะพาน = ค่าเฉลี่ยถ่วงน้ำหนักของ EHI ทุกชนิดชิ้นส่วน |
| **สถานะ** | ชื่อที่ได้จากการดูว่าคะแนนตกช่วงไหน เช่น 90–100 = "ดีพอใช้" ใช้ได้ทั้ง EHI และ T-BHI |
| **ช่วงคะแนน** | เส้นแบ่งที่ตัดสินว่าคะแนนเท่าไรได้สถานะอะไร (ไฟล์นี้กำลังแก้ตัวนี้) |
| **กฎบังคับสถานะ** | ถ้าเจอระดับ 2/1/0 ในคาน เสา หรือหัวเสา สถานะของสะพานต้องไม่ดีกว่า ชำรุด/วิกฤต/วิบัติ ไม่ว่าคะแนนจะสูงแค่ไหน |
| **ใจดี / เข้ม** | ใจดี = ต้องเสียหายเยอะ สถานะจึงจะตก · เข้ม = เสียหายนิดเดียว สถานะก็ตก |
| **ทิศอันตราย** | ระบบบอกว่าสะพานดีกว่าความจริง ซึ่งอันตรายที่สุดสำหรับเครื่องคัดกรอง เพราะสะพานที่ควรตรวจจะไม่ถูกส่งไปตรวจ |

ตัวอย่างการคิด EHI: ชิ้นส่วนที่ 90% เป็นระดับ 5 และ 10% เป็นระดับ 3 → EHI = 100 × (0.9 × 1.00 + 0.1 × 0.67) = 100 × (0.90 + 0.067) = **96.7**

## 0. สรุปสั้นที่สุด

**แนะนำทางเลือก ง: ไม่แก้ค่า C แก้แค่เส้นแบ่งช่วงคะแนน**

กติกาของทางเลือก ง เขียนเป็นภาษาคนได้ว่า:
> ชิ้นส่วนจะได้ชื่อสถานะของระดับไหน คะแนนต้อง**ไม่ต่ำกว่าชิ้นส่วนที่อยู่ระดับนั้นทั้งชิ้น** แต่ยอมให้มีส่วนที่แย่กว่าหนึ่งขั้นได้ไม่ถึง 5% ของพื้นที่

| สถานะ | ช่วงเดิม (เอกสาร T-BHI) | **ช่วงที่เสนอ (ง)** | ชิ้นส่วนที่อยู่ระดับนี้ทั้งชิ้นได้คะแนน |
|---|---|---|---|
| ดีมาก | 100 พอดีเท่านั้น | **99.15 ขึ้นไป** | 100 |
| ดีพอใช้ | 90 ถึงต่ำกว่า 100 | **82.20 ถึงต่ำกว่า 99.15** | 83 |
| พอใช้ | 70 ถึงต่ำกว่า 90 | **65.30 ถึงต่ำกว่า 82.20** | 67 |
| ชำรุด | 50 ถึงต่ำกว่า 70 | **32.20 ถึงต่ำกว่า 65.30** | 33 |
| วิกฤต | 30 ถึงต่ำกว่า 50 | **16.15 ถึงต่ำกว่า 32.20** | 17 |
| วิบัติ | ต่ำกว่า 30 | **ต่ำกว่า 16.15** | 0 |

**เหตุผลสั้นๆ:**
- แก้ปัญหาที่อาจารย์ชี้ได้ครบทั้งสองข้อ
- ไม่ต้องเปลี่ยนค่า C ที่มาจากเอกสาร T-BHI
- เมื่อชิ้นส่วนมีหลายระดับปนกัน ทางเลือกนี้เข้มพอๆ กับข้อเสนอ ข จึงปลอดภัยกว่าข้อเสนอ ก

## 1. อาจารย์ชี้ปัญหาอะไร (ความเห็น 30 ต.ค.)

**ปัญหาที่ 1: ชื่อสถานะต่ำกว่าชื่อระดับหนึ่งขั้นทุกระดับ**
- ชิ้นส่วนที่เป็นระดับ 4 (ดีพอใช้) ทั้งชิ้นได้คะแนน 83 แต่ 83 ตกช่วง 70–90 ซึ่งชื่อ "พอใช้"
- ระดับ 3 (พอใช้) ได้ 67 ซึ่งชื่อ "ชำรุด"
- ระดับ 2 (ชำรุด) ได้ 33 ซึ่งชื่อ "วิกฤต"

**ปัญหาที่ 2: "ดีมาก" ต้องได้ 100 พอดี** ถ้าระบบเจอความเสียหายนิดเดียวแม้จุดเดียว สะพานจะไม่ได้ "ดีมาก" เลย และระบบ AI ก็ตรวจผิดได้ จุดที่ตรวจผิดจุดเดียวก็ทำให้หลุดจาก "ดีมาก" ได้

อาจารย์ขอให้ "ลองเสนอค่า C หรือช่วงคะแนน ที่ทำให้ชิ้นส่วนที่อยู่ระดับใดทั้งชิ้นได้สถานะชื่อเดียวกับระดับนั้น แล้วมาคุยกัน"

**ปัญหาที่ 3 (ผู้จัดทำพบเพิ่ม):**
- เล่มกำหนดว่าระดับ 0 (วิบัติ) จะไม่ตัดสินจากภาพ (ข้อ 3.7.1)
- แต่ถ้าใช้ช่วงเดิม ชิ้นส่วนระดับ 1 ทั้งชิ้นได้ 17 ซึ่งตกช่วง "วิบัติ" (ต่ำกว่า 30)
- ระบบจะประกาศสถานะที่เอกสารบรรยายว่า "ปิดสะพาน หรือทุบทิ้งแล้วก่อสร้างใหม่" ทั้งที่ไม่ได้เจอระดับ 0 เลย

## 2. ตัวเลขเดิมมาจากไหน (เอกสาร T-BHI)

- **ค่า C (ตาราง 4.12 หน้า 55):** ระดับ 5 = 1.00 · 4 = 0.83 · 3 = 0.67 · 2 = 0.33 · 1 = 0.17 · 0 = 0
  - เอกสารได้ค่าเหล่านี้จากคู่มือ AASHTO ของสหรัฐฯ ซึ่งมี 4 ขั้นที่ค่า 1.00, 0.67, 0.33, 0 แล้วแทรกค่ากลางเพิ่มให้ครบ 6 ขั้นแบบเส้นตรง (0.83 อยู่กลางระหว่าง 1.00 กับ 0.67 และ 0.17 อยู่กลางระหว่าง 0.33 กับ 0)
  - เอกสารเน้นว่าวิธีนี้ทำให้คะแนนของเรา "เทียบกับ AASHTO ได้" (หัวข้อ 4.4.3)
- **ช่วงคะแนน (ตาราง 4.10 หน้า 53):** 100 / 90 / 70 / 50 / 30 แต่ละช่วงมีคำแนะนำการซ่อมกำกับ ได้แก่ ซ่อมตามปกติ / ซ่อมเชิงป้องกัน / ซ่อมตามกำหนดเวลา / ซ่อมพิเศษ / ซ่อมเร่งด่วนหรือบูรณะ / ปิดสะพานหรือทุบทิ้ง
- **ที่มาของเส้นแบ่ง (หน้า 57):**
  - เอกสารบอกว่า 90 กับ 70 "อ้างอิงตามแนวปฏิบัติของ FHWA" (หน่วยงานทางหลวงสหรัฐฯ) **แต่ยังหาต้นทางยืนยันไม่ได้** เล่มจึงอ้างเอกสาร T-BHI แทน
  - 50 กับ 30 ผู้เขียนเอกสารเพิ่มเอง
- **เอกสารไม่ได้ตั้งใจให้ชื่อสถานะตรงกับระดับ (หน้า 57):** เอกสารเขียนว่าช่วงคะแนน "ไม่ทำหน้าที่จำแนกย้อนกลับจาก T-BHI เป็นระดับสภาพ" แต่มีไว้บอกว่าควรซ่อมแบบไหน
- **กฎบังคับสถานะ (ตาราง 4.11 หน้า 53):** เจอระดับ 2 ในชิ้นส่วนหลัก สถานะไม่ดีกว่า "ชำรุด" · เจอระดับ 1 ไม่ดีกว่า "วิกฤต" · เจอระดับ 0 เป็น "วิบัติ"
- **ระดับของชิ้นส่วน (หน้า 56):** ถ้าชิ้นส่วนเดียวมีหลายระดับ ให้นับเป็น "ระดับที่แย่ที่สุด"

- **ช่วงคะแนน:** 100 / 90 / 70 / 50 / 30
- **ข้อดี:**
  - ไม่ต้องแก้ ตัวเลขอ้างเอกสาร T-BHI ได้ทุกตัว
  - เข้มที่สุดเมื่อชิ้นส่วนมีหลายระดับปนกัน
- **ข้อเสีย:**

### ทางเลือก ก (อยู่ในเล่ม v11): ค่า C เดิม เปลี่ยนช่วงคะแนน

- **ค่า C:** เดิม
- **ช่วงคะแนน:** 100 / 75 / 50 / 25 / 10
- **หลักคิด:** เส้นแบ่ง 75, 50, 25 อยู่ตรงกลางระหว่างคะแนนของระดับที่ติดกัน เช่น 75 อยู่กลางระหว่าง 83 กับ 67
- **ข้อดี:**
  - ผ่านเกณฑ์ข้อ 1, 4, 5, 6
  - ค่า C ยังอ้างเอกสาร T-BHI ได้
- **ข้อเสีย:**
  - "ดีมาก" ยังต้องได้ 100 พอดี (ไม่ผ่านเกณฑ์ข้อ 2)

- **สรุป:** ไม่แนะนำ

### ทางเลือก ข (อยู่ในเล่ม v11): ช่วงคะแนนเดิม เปลี่ยนค่า C

- **ค่า C:** 1.00 / 0.95 / 0.80 / 0.60 / 0.40 / 0
- **ช่วงคะแนน:** เดิม (100 / 90 / 70 / 50 / 30)
- **หลักคิด:** ค่า C ใหม่คือตรงกลางของแต่ละช่วงเดิม เช่น 95 อยู่กลางช่วง 90–100 (ผู้จัดทำอ่านหลักคิดนี้ออกมาเอง เล่มไม่ได้เขียนไว้)
- **ข้อดี:**
  - ผ่านเกณฑ์ข้อ 1, 5, 6
  - เก็บช่วงคะแนนและคำแนะนำการซ่อมของเอกสารไว้ได้
  - **เข้มกว่า ก** เมื่อชิ้นส่วนมีหลายระดับปนกัน
- **ข้อเสีย:**
  - "ดีมาก" ยังต้องได้ 100 พอดี (ไม่ผ่านเกณฑ์ข้อ 2)
  - ค่า C เป็นตัวเลขที่ผู้จัดทำตั้งใหม่ทั้งชุด **จึงเทียบกับ AASHTO ไม่ได้แล้ว** เช่น ระดับ 3 ที่เทียบ AASHTO ได้ 0.67 กลายเป็น 0.80
  - คะแนนกระโดดจากระดับ 1 (0.40) ลงไประดับ 0 (0) มาก
  - ถ้าจะแก้เรื่อง "ดีมาก" ด้วย ต้องเปลี่ยนช่วงคะแนนอีก กลายเป็นเปลี่ยนทั้งสองอย่าง
- **สรุป:** ใช้ได้ถ้าอาจารย์ยอมเปลี่ยนค่า C แต่เรื่อง "ดีมาก" ยังแก้ไม่ได้

### ทางเลือก ค: เส้นแบ่งอยู่ตรงกลางทุกช่วง (Claude เคยเสนอในแชต ตอนนี้ถอนแล้ว)

- **ค่า C:** เดิม
- **ช่วงคะแนน:** 91.5 / 75 / 50 / 25 / 8.5 (เหมือน ก แต่ขอบบนสุดก็ใช้จุดกึ่งกลางด้วย)
- **ข้อดี:** ผ่านเกณฑ์ข้อ 1, 2, 4, 5, 6 และอธิบายง่ายว่า "ได้สถานะของระดับที่คะแนนใกล้ที่สุด"
- **ข้อเสีย: ใจดีที่สุดในทุกทางเลือก**
  - ชิ้นส่วนที่ 10% เป็นระดับ 2 ยังได้ "ดีมาก" (กรณี G)
  - ความเสียหายระดับ 4 ครอบได้ถึงครึ่งชิ้นส่วนก็ยังเป็น "ดีมาก"
- **สรุป:** ไม่แนะนำ (ไม่ผ่านเกณฑ์ข้อ 3)

### ทางเลือก ง: ค่า C เดิม เส้นแบ่ง = คะแนนของระดับนั้นทั้งชิ้น ลบค่าเผื่อเล็กน้อย (แนะนำ)

- **ค่า C:** เดิม
- **วิธีหาเส้นแบ่ง (คิดทีละสถานะ):**
  1. ดูคะแนนของชิ้นส่วนที่อยู่ระดับนั้นทั้งชิ้น เช่น "ดีพอใช้" (ระดับ 4) = 83
  2. ดูคะแนนของระดับที่แย่กว่าหนึ่งขั้น คือระดับ 3 = 67
  3. หาระยะห่าง: 83 − 67 = 16
  4. ค่าเผื่อ = 5% ของระยะห่าง: 16 × 0.05 = 0.8
  5. เส้นแบ่ง = 83 − 0.8 = **82.20**

  ทำแบบเดียวกันครบทุกสถานะ:

| สถานะ | คะแนนทั้งชิ้น | ระดับที่แย่กว่าหนึ่งขั้น | ห่างกัน | ค่าเผื่อ (5%) | **เส้นแบ่ง** |
|---|---|---|---|---|---|
| ดีมาก | 100 | 83 | 17 | 0.85 | **99.15** |
| ดีพอใช้ | 83 | 67 | 16 | 0.80 | **82.20** |
| พอใช้ | 67 | 33 | 34 | 1.70 | **65.30** |
| ชำรุด | 33 | 17 | 16 | 0.80 | **32.20** |
| วิกฤต | 17 | 0 | 17 | 0.85 | **16.15** |
| วิบัติ | ต่ำกว่า 16.15 | | | | |

- **ทำไมใช้ 5%:** ตรงกับนิยาม "บริเวณกว้าง" ในข้อ 3.7.1 ของเล่มเอง (ความเสียหาย ≥ 5% ของพื้นที่ชิ้นส่วน) อ่านได้ว่า "ความเสียหายที่ยังไม่ถึงขั้นบริเวณกว้าง จะไม่ทำให้ชื่อสถานะตก"
- **ข้อดี:**
  - ผ่านเกณฑ์ครบทั้ง 6 ข้อ
  - "ดีมาก" ยอมให้มีความเสียหายระดับ 4 ได้ถึง 5% ของพื้นที่ จุดเล็กจุดเดียวไม่ทำให้หลุด
  - **ความเสียหายยิ่งหนัก ยิ่งได้ค่าเผื่อน้อยลงเอง** ระดับ 3 ราว 2.6% ระดับ 2 ราว 1.3% ระดับ 1 ราว 1.0% โดยไม่ต้องตั้งกฎเพิ่ม
  - เมื่อชิ้นส่วนมีหลายระดับปนกัน เข้มพอๆ กับ ข (กรณี E, F, G, I ได้ผลเท่า ข)
  - ไม่แตะค่า C จึงยังอ้างเอกสาร T-BHI และเทียบ AASHTO ได้
  - ใช้หลักเดียว วิธีคิดเดียว ไม่ต้องตั้งตัวเลขแยกทีละช่วง
- **ข้อเสีย:**
  - **ตัวเลขไม่กลม** (99.15, 82.20, …) อาจดูแปลก และ**ห้ามปัดเป็นจำนวนเต็ม** เพราะผลจะเปลี่ยน
    - ตัวอย่าง: ถ้าปัด 99.15 เป็น 99 ชิ้นส่วนที่มีระดับ 3 อยู่ 3% จะกลายเป็น "ดีมาก" (กรณี J)
    - ถ้าจะปัด ให้ปัดขึ้นเท่านั้น ซึ่งเป็นด้านเข้มกว่า
  - **ช่วงคะแนนไม่ตรงเอกสาร T-BHI แล้ว** ต้องเขียนในเล่มว่า "ผู้จัดทำปรับ" และตัวเลข 90/70 ที่เอกสารบอกว่ามาจาก FHWA จะหายไป (แต่ตัวเลขนั้นก็ยืนยันต้นทางไม่ได้อยู่แล้ว)
  - **ค่าเผื่อ 5% ผูกกับนิยาม "บริเวณกว้าง"** ซึ่งอาจารย์ยังไม่ได้ยืนยัน ถ้านิยามเปลี่ยน ค่าเผื่อควรเปลี่ยนตาม
  - ชิ้นส่วนรอง (พื้น ราว) ที่มีระดับ 1 อยู่ 20% ยังได้ "ดีพอใช้" (กรณี H) ใจดีกว่า ข เล็กน้อย ถ้าเป็นคาน เสา หรือหัวเสา กฎบังคับจะดึงลงเป็น "วิกฤต" อยู่แล้ว ถ้ากังวลชิ้นส่วนรอง ให้ใช้กฎเสริมข้างล่าง
- **กฎเสริม (เลือกใส่หรือไม่ใส่ก็ได้):** "ดีมาก" ต้องไม่เจอระดับ 2 หรือแย่กว่าในชิ้นส่วนใดเลย รวมพื้นกับราวด้วย
- **แบบที่เข้มที่สุด (ง0 ไม่มีค่าเผื่อ):**
  - เส้นแบ่ง = 100 / 83 / 67 / 33 / 17 เข้มที่สุดที่ยังผ่านเกณฑ์ข้อ 1
  - แต่ "ดีมาก" กลับไปต้อง 100 พอดี (ไม่ผ่านเกณฑ์ข้อ 2)
  - เก็บไว้ถ้าอาจารย์อยากให้เข้มที่สุด

### ทางเลือก จ: ไม่แก้ตัวเลข เปลี่ยนชื่อสถานะแทน

- **ค่า C และช่วงคะแนน:** เดิมทั้งหมด
- **ชื่อสถานะ:** เปลี่ยนเป็นคำแนะนำการซ่อมตามตาราง 4.10 (ซ่อมตามปกติ / เชิงป้องกัน / ตามกำหนดเวลา / พิเศษ / เร่งด่วนหรือบูรณะ / ปิดสะพาน)
- **หลักคิด:** ตรงกับที่เอกสารหน้า 57 เขียนว่าช่วงคะแนนมีไว้บอกการซ่อม ไม่ได้มีไว้แปลงกลับเป็นระดับ
- **ข้อดี:**
  - ไม่ต้องแก้ตัวเลขเลย อ้างเอกสารได้ครบ
  - ชื่อไม่ชนกับชื่อระดับแล้ว ปัญหาที่ 1 จึงหายไป
- **ข้อเสีย:**
  - ไม่ได้ทำตามที่อาจารย์ขอตรงๆ
  - "ซ่อมตามปกติ" ยังต้องได้ 100 พอดี
  - ระดับ 1 ทั้งชิ้นยังได้ "ปิดสะพาน"
  - เครื่องคัดกรองไม่ควรแนะนำวิธีซ่อม เพราะเกินขอบเขตของเล่ม (1.3 ข้อ 5)
- **สรุป:** เก็บไว้เป็นทางสำรอง ถ้าอาจารย์อยากคงตัวเลขเอกสารไว้

## 6. เข้ากับกฎบังคับสถานะไหม

- **ชิ้นส่วนที่อยู่ระดับเดียวทั้งชิ้น:** ในทางเลือก ก ข ค ง ระดับ 2 ทั้งชิ้นได้ "ชำรุด" และระดับ 1 ได้ "วิกฤต" ตรงกับเพดานของกฎบังคับพอดี ส่วนช่วงเดิมให้ "วิกฤต" และ "วิบัติ" ซึ่งแย่กว่าที่กฎกำหนดโดยไม่มีเหตุผล
- **ระดับ 0:** ทุกทางเลือกยกเว้น "เดิม" จะได้ "วิบัติ" ก็ต่อเมื่อเจอระดับ 0 เท่านั้น ตรงกับที่เล่มไม่ตัดสินระดับ 0 จากภาพ
- **ชิ้นส่วนที่มีหลายระดับปนกัน:** สถานะสุดท้าย = ตัวที่แย่กว่าระหว่าง "สถานะจากคะแนน" กับ "เพดานจากกฎบังคับ"
  - ข้อความใต้ตาราง 2.7 ที่ว่า "ยังไม่ได้ทดสอบร่วมกับกฎบังคับสถานะ" อ้างผลในส่วนที่ 5 ได้แล้ว
  - **ยังไม่ได้ทดสอบระดับทั้งสะพาน** ซึ่งมีหลายชิ้นส่วน และมีน้ำหนัก W และค่า q
- **ช่วงคะแนนใช้กับ T-BHI ของทั้งสะพานด้วย** (ข้อ 3.7.6) ไม่ใช่แค่ EHI ของชิ้นส่วน ทางเลือกที่เลือกจะใช้ทั้งสองระดับ

## 7. ถ้าเลือกทางเลือก ง ต้องแก้เล่มตรงไหน

ตำแหน่งข้างล่างมาจากไฟล์สรุปเล่ม v11 **ยังไม่ได้เปิดเล่มตรวจข้อความจริงทีละจุด**

1. **2.2.3 ตาราง 2.7 และข้อความใต้ตาราง** (หน้า 12–13): เปลี่ยนเป็นตารางเดียว (ค่า C เดิม + ช่วงใหม่ + สถานะที่ได้) และลบ "(ลงรายละเอียดหลังนำเสนอ)"
2. **3.7.6:** เปลี่ยนช่วงคะแนนสถานะ และเพิ่มวิธีหาเส้นแบ่งพร้อมเหตุผลเรื่องค่าเผื่อ 5%
3. **ตาราง 2.9 (ที่มาของตัวเลข):** เปลี่ยนที่มาของ "ช่วงคะแนนสถานะ" จาก "เอกสาร T-BHI" เป็น "ผู้จัดทำปรับจากเอกสาร T-BHI" (ค่า C ยังเป็นของเอกสาร T-BHI)
4. **1.3 ข้อ (4):** ตอนนี้เขียนว่าช่วงคะแนนเป็นไปตามเอกสาร T-BHI ต้องแก้ให้ตรง
5. **3.7.1:** ถ้านิยาม "บริเวณกว้าง 5%" เปลี่ยน ให้เขียนโยงว่าค่าเผื่อใน 3.7.6 ใช้ตัวเลขเดียวกัน

## 8. คำถามสำหรับอาจารย์

1. อาจารย์รับทางเลือก ง ได้ไหม หรืออยากคงตัวเลขเอกสาร T-BHI ไว้แล้วเปลี่ยนชื่อสถานะแทน (จ)
2. ค่าเผื่อ 5% ผูกกับนิยาม "บริเวณกว้าง" ได้ไหม (นิยามนี้ยังรออาจารย์ยืนยัน)
