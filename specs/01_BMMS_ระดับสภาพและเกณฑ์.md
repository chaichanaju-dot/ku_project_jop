## 1. ระดับสภาพ (BMMS ตาราง 4-1, PDF หน้า 98–99) [A]
| ระดับ | ชื่อ | หมายเหตุ |
|---|---|---|
| 5 | ดีมาก | |
| 4 | ดีพอใช้ | |
| 3 | พอใช้ | |
| 2 | ชำรุด | |
| 1 | วิกฤต | |
| 0 | วิบัติ | **ไม่กำหนดจากภาพ** (เล่ม 3.7.1) |

- ระดับ 4–0 นิยามด้วยการซ่อมบำรุง ไม่ใช่ตัวเลขความเสียหาย
- สภาพรวมสะพาน = **ค่าต่ำสุด** ของส่วนบน/ส่วนล่าง (ส่วนประกอบรองไม่เข้า) — BMMS PDF หน้า 78 (3-31), 96 (3-49), ตัวอย่างคำนวณหน้า 370 (บน 4 ล่าง 3 รอง 1 → รวม 3) · **ไม่มีน้ำหนักชิ้นส่วน ไม่มีดัชนี 0–100 ไม่มีเกณฑ์เป็นพื้นที่**
- ความถี่ตรวจ: ปกติ 1–2 ปี · หลัก 4 ปี (OCR ≤3) / 6 ปี (OCR ≥4) · งานนี้ไม่ใช่การตรวจประเภทใดของ BMMS (เป็นการคัดกรองก่อน)

## 2. ความกว้างรอยร้าว (มม.) — ตาราง 4-3 / 4-5 / 4-9 / 4-13 [A]
ตัวเลขตรวจกับต้นฉบับแล้ว (4-5: PDF หน้า 135–137; RC: หน้า 109–111, 165–168, 205–208)

| ระดับ | RC | PC (คานตามยาว / พื้น / คานรัดหัวเสา / เสาเข็ม) |
|---|---|---|
| 4 | <1.6 (Hairline) | <0.10 |
| 3 | 1.6–3.2 | 0.10–0.23 |
| 2 | 3.2–4.8 | 0.25–0.76 |
| 1 | >4.8 | >0.76 |

- **ช่อง 0.23–0.25 มม. ของ PC ว่างในต้นฉบับ** — เล่มจัดเป็นระดับ 2 (กฎ "ระดับที่แย่กว่า") [C]
- เสาตอม่อ (4-13) และฐานราก (4-17) มีเฉพาะเกณฑ์ RC
- ค่าตกพอดีขอบ = ระดับที่แย่กว่า
- **BMMS ไม่ระบุที่มาของตัวเลข** → เขียนว่า "ตามที่กรมทางหลวงกำหนด" ห้ามเขียนว่าตาม ACI/AASHTO
- ระดับ 2/1 ผูกกับเงื่อนไขอื่นด้วย: รอยแตกเนื่องจากเหล็กเสริมเป็นสนิม (RC ระดับ 2; ใหญ่ = 1) · **รอยเฉือน/ดัดที่กระทบกำลัง ทุกขนาด = ระดับ 1** · PC เห็นลวดอัดแรงบางส่วน = 2 / จำนวนมาก = 1
- Hairline = วัดไม่ได้ด้วยอุปกรณ์ธรรมดา (PC ต้องใช้ crack gauge) — PDF หน้า 99–100
- ภาพวัดความลึกกะเทาะ/เสียหน้าตัดไม่ได้ → ใช้ตัวบ่งชี้ทางอ้อม + ค่าความมั่นใจต่ำ

## 3. เกณฑ์รายประเภทความเสียหาย (ระดับตาม BMMS) [A]
| ประเภท | ระดับ 4 | ระดับ 3 | ระดับ 2 | ระดับ 1 |
|---|---|---|---|---|
| Spalling (กะเทาะ) | เล็กน้อย ลึกไม่ถึงเหล็ก | เล็กน้อยหลายจุด/บริเวณกว้าง ไม่ถึงเหล็ก | ถึงเหล็กเสริม | ถึงเหล็กหลายจุด/บริเวณกว้าง |
| Exposed_Rebar | (ไม่มีแถว) | ถึงเหล็กแต่ไม่กระทบกำลัง (อาจมีสนิม) | เหล็กเป็นสนิม; PC เห็นลวดบางส่วน | เสียหายมาก; PC เห็นลวดมาก; แอ่นผิดปกติ |
| Honeycomb | โพรงเล็ก ไม่ถึงเหล็ก | โพรงเล็กหลายจุด/โพรงใหญ่ ไม่ถึงเหล็ก | **ไม่มีแถว** | **ไม่มีแถว** |
| Efflorescence | คราบน้ำเล็กน้อย | คราบน้ำมาก พบคราบเกลือ | **ไม่มีแถว** | **ไม่มีแถว** |
| Rust_Stain | **BMMS ไม่มีเกณฑ์ระดับแยก** (มีแค่ประโยคว่าปรากฏตามรอยแตก, PDF หน้า 99) | | | |

- ตัวเลขขนาดใน BMMS ไม่เชื่อมกันเอง (Scaling 6 มม./1.2/2.5 ซม. หน้า 100 vs ปูนทรายหลุดล่อน 5–10/10–20/>20 มม. หน้า 109–111) → อ้างชุดเดียว (ตาราง) อย่าผสม
- กะเทาะลึก <2.5 ซม. / ⌀≈15 ซม. = เล็ก (หน้า 104)
- "เล็ก/ใหญ่/หลายจุด" ไม่มีตัวเลขใน BMMS → นิยามของเล่ม "หลายจุด" = ≥3 จุดต่อชิ้นส่วนในภาพ หรือ ≥ร้อยละ 5 ของพื้นที่ชิ้นส่วน [C] (ยังรออาจารย์ยืนยัน)
- Honeycomb แย่สุดระดับ 3 / Efflorescence แย่สุดระดับ 3 — ตรงกับที่ BMMS ไม่มีแถวระดับ 2–1

## 4. การจับคู่องค์ประกอบ BMMS → 5 ประเภทของเล่ม (ตาราง 2.1) [C]
| ประเภทในเล่ม | องค์ประกอบ BMMS ที่รวม |
|---|---|
| เสา | เสาตอม่อ, กำแพงตอม่อ |
| คาน | คานหลัก, ค้ำยันคาน/คานขวาง (ทุกชนิด) |
| หัวเสา | คานรัดหัวเสา |
| พื้น | พื้นสะพาน |
| ราว | ราวสะพาน/แผงกั้น |
| **นอก T-BHI** | ค้ำยันตอม่อ ฐานราก เสาเข็ม ผิวทาง รอยต่อ ระบายน้ำ แผ่นรองรับ |

- วัสดุ: คานหลัก = PC (ยืนยันจากรายงานและรูปถ่าย) · **เสา/หัวเสา = RC ตามที่เล่มตั้งไว้ ยังไม่มีเอกสารยืนยัน** (ต้องถามวิศวกร/แบบ as-built/ทะเบียน BMMS) · พื้นและราว: เล่ม v11 ไม่ได้ระบุวัสดุ

## 5. ที่ค้าง/ข้อควรระวัง
- PC rebar corrosion (ตาราง "เหล็กเสริมเป็นสนิม" 4.3.6 ของ PC) ถูกข้ามในเอกสาร T-BHI — ยังไม่ตัดสินว่าจงใจ (บท3_3.7 §4 ข้อ 5)
- Rust_Stain ขัดกับ AASHTO ที่ให้ "คราบเกลือ + สนิม" = CS3 (≈ระดับ 2) ขณะที่เล่มให้เพดานระดับ 3 + กฎดัน (บท3_3.7 §2.6)
- อย่าอ้างวิกิพีเดียเรื่องสะพาน (กล่องข้อมูล "Box Girder" ผิด)
