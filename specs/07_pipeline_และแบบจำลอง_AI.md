# 07 — Pipeline 6 ขั้น และแบบจำลอง AI (VLM, SAM, YOLO26)

> **ที่มา:** `CLAUDE.md` ข้อ 3 · เล่ม v11 หัวข้อ 3.2–3.5 · โน้ต G6 (โมเดล), G7 (VLM/fine-tune), G8 (SHM/VLM) ใน `02_…/2_…/โน้ตค้นคว้า_G1-G8/`
> **สถานะ:** **ยังไม่ได้ฝึกโมเดลใดๆ ยังไม่มีผลทดลอง** · รุ่น VLM ยังไม่ตัดสิน (เล่มบทที่ 2 ห้ามระบุรุ่น/Qwen; ชื่อรุ่นไปอยู่บทที่ 3 เมื่อตัดสินใจแล้ว)

## 1. Pipeline (ทำงานกับภาพต้นฉบับภาพเดียวกัน; ขั้น 3 และ 4 ขนานกัน)
| ขั้น | เล่ม | ทำอะไร | ผลที่ได้ |
|---|---|---|---|
| 1 | 3.3 | เก็บภาพ Matrice 4E แยกตามชิ้นส่วนและรอบบิน + เลเซอร์ 4 จุด + crack scale | ภาพดิบ + บันทึกการบิน |
| 2 | 3.4 | คัดภาพ (ความคมชัด Laplacian, แสง, จุดเลเซอร์) + ป้ายชิ้นส่วนระดับภาพ | รายการภาพ + ป้ายชิ้นส่วน |
| 3 | 3.5 | **VLM (ปรับแต่ง)** ระบุชนิด+กรอบชิ้นส่วน 5 ประเภท และตำแหน่ง+ชนิดความเสียหาย 6 ประเภท → กรอบส่งให้ **SAM (ปรับแต่ง)** วาดมาสก์ → จับคู่ด้วยกรอบชิ้นส่วนในภาพเดียวกัน | มาสก์ความเสียหาย + สัดส่วนต่อชิ้นส่วน |
| 4 | 3.6 | เลเซอร์ 4 จุด → HSV → โฮโมกราฟี → s = d/p → ความกว้างรอย (เปอร์เซ็นไทล์ 95) | สเกลต่อภาพ, ความกว้าง |
| 5 | 3.7 | Python กฎ: ลักษณะความเสียหาย → ระดับ 0–5 → EHI → T-BHI → สถานะ + ความมั่นใจ | ดัชนีตรวจย้อนได้ |
| 6 | 3.8 | เทียบวิศวกรหลายท่าน 3 ระดับ | ตารางสับสน, สถานะตรงไหม, พลาดทางอันตรายไหม |

- คิดสเกลและสัดส่วนความเสียหาย **ต่อภาพ** แล้วรวมที่ระดับสัดส่วน (ไม่บวกพิกเซลข้ามภาพ เพราะต่างมาตราส่วน; ภาพซ้อนอาจนับซ้ำ → ลดซ้อนที่ต้นทาง + ทดสอบความไว)
- **ไม่แบ่งส่วนชิ้นส่วนเป็นมาสก์** (ตัด 31 ต.ค.) ตัวหาร = **กรอบชิ้นส่วน** จาก VLM (Claude ตัดสินแทนทีม **ยังไม่ได้ถามอาจารย์**) · ข้อเสนอค้าง: กรอบอาจใหญ่กว่าชิ้นส่วนจริง (4 วิธี ก/ข/ค/ง ดู 09)
- ตัดออกจากแผนแล้ว: โมเดล 3 มิติ/โฟโตแกรมเมตรี/ออร์โท/Agisoft/Pix4D · พิกัด GPS · GSD · QWK · human-in-the-loop · Proposal v22

## 2. VLM (3.5.3)
- เลือกโมเดลภาษาภาพ **แบบเปิดน้ำหนักที่ระบุกรอบได้** ปรับด้วย **LoRA** บนเครื่องที่มี (รุ่น/ขนาดยืนยันหลังทดสอบ) · ตอบเป็น **JSON ชนิด+กรอบพิกเซลเท่านั้น** ไม่ตอบขนาด/ระดับ · ตรวจโครงสร้างคำตอบทุกรายการ รายการไม่ผ่านถูกทิ้งและนับเป็นสถิติ
- ปรับแต่งด้วยคู่ภาพ-JSON สร้างอัตโนมัติจากป้าย
- **สมมติฐานที่ต้องทดสอบ (ไม่ใช่ข้อเท็จจริง):** VLM ให้กรอบความเสียหายที่ recall@IoU0.5 ไม่ต่ำกว่า YOLO26 — เลือกบน **ชุดตรวจสอบ ไม่ใช่ชุดทดสอบ**
- เหตุผลที่ให้ตอบเฉพาะชนิด+กรอบ: ภาพหลอน (Chen 2025), Zhang & Liu 2025 พบตัวเลขพิกเซลที่ VLM เขียนผิด, Yasuno 2026 (arXiv 2605.27452) พบ mode collapse ใน VLM fine-tune
- เหตุผลที่ไม่ใช้ QLoRA: บีบตัวรับภาพ 4 บิตทำให้ recall ตก

## 3. SAM (3.5.3)
- กรอบจาก VLM เป็นพรอมต์แบบกรอบ **1 มาสก์/1 กรอบ** · ตั้งต้น SAM 3 (Carion 2025) · ปรับด้วย LoRA โดยสร้างกรอบฝึกจากโพลิกอน + เติมความคลาดเคลื่อนสุ่ม · วัด IoU + Dice เมื่อรับกรอบจริงและกรอบจาก VLM
- **ใช้กับความเสียหายเท่านั้น** (ชิ้นส่วนใช้กรอบ เพราะภาพระยะใกล้บินแยกชิ้นส่วน เป้าหมายเกือบเต็มภาพ)
- เลือกมาสก์แทนกรอบสำหรับความเสียหาย เพราะกรอบให้พื้นที่เกิน โดยเฉพาะรอยคด (อ้าง ศุภศิษฏ์ 2569ก)
- กติกาภาษา: บทที่ 2 เขียน "SAM" ไม่ระบุรุ่น · บทที่ 3 ระบุ SAM 3 ได้ · อ้างงานคนอื่นคงชื่อ SAM 3 ได้
- ไม่มีหลักฐาน SAM 3 บนสะพานนอกพรีพรินต์ (Malaisree, Yasuno, Song) · SAM2 ใน Çelik 2025 ใช้ไม่ดีกับรอยร้าว/ขอบไม่คม

## 4. ทางสำรอง YOLO26 แบบกรอบ (3.5.2)
- เทียบขนาด s/m/l ตามขีดจำกัด GPU บน **ชุดตรวจสอบ** · ใช้ถ้า VLM ปรับแต่ง/รันไม่ได้ หรือให้กรอบต่ำกว่า YOLO26 (ประเภทไหนต่ำกว่า → ใช้ YOLO26 สำหรับประเภทนั้น) · ป้ายชิ้นส่วนจากบันทึกการบิน
- **จุดตัดสินใจ = สิ้นเดือน ม.ค. 2570** หลังรอบฝึกแรก · **ระบบหลักต้องเดินจนจบโดยไม่พึ่ง VLM** (อาจารย์สั่ง 30 ต.ค.)

## 5. การจับคู่ความเสียหาย–ชิ้นส่วน (3.5.4) และข้อจำกัด
- ส่วนของมาสก์ในกรอบชิ้นส่วนใดนับเป็นของชิ้นส่วนนั้น (ภาพเดียวกัน ไม่ข้ามภาพ ไม่ใช้พิกัด GPS — Gou 2026: GNSS ใต้สะพานคลาดเดซิเมตร–>1 ม.)
- ข้อจำกัด: กรอบอาจรวมพื้นหลัง → สัดส่วนต่ำกว่าจริงเล็กน้อย จึงรายงานระดับแย่สุดคู่ EHI และกฎบังคับสถานะไม่ขึ้นกับสัดส่วน

## 6. ผลที่คาดไว้ในเล่ม 3.8 (7 ข้อ — รายงานตามค่าจริง ไม่ตั้งเกณฑ์ผ่าน/ไม่ผ่านล่วงหน้า)
ผลชิ้นส่วนรายประเภท · VLM ให้กรอบเทียบตัวตรวจจับได้ไหม + มาสก์แม่นเพียงใด · ช่วงเงื่อนไขวัดได้ + ความคลาด + รายการวัดไม่ได้ · โปรแกรมตรวจย้อน · ตารางเทียบวิศวกร + พลาดทางอันตรายบ่อยแค่ไหน · รายงานคัดกรองสะพาน + จุดควรส่งตรวจ · ชุดภาพติดป้าย + กติกา

## 7. การเทียบวิศวกร (3.8)
- วิศวกรโยธาที่มีประสบการณ์ตรวจสะพาน **"หลายท่าน"** ประเมินระดับ 0–5 รายชิ้นส่วน ~15–20 ชิ้นส่วน จากภาพชุดเดียวกัน แยกกัน ไม่เห็นผลระบบ · ตรวจความเห็นตรงกันเองก่อน · เลือกชิ้นส่วนให้มีทั้งสภาพดีและเสียหาย · ชุดทดสอบใช้ครั้งเดียวตอนท้าย
- 3 ระดับ: (1) ชนิดชิ้นส่วน/ชนิดและมาสก์ความเสียหาย แยกเป็นขั้น (2) ระดับรายชิ้นส่วน (ตารางสับสน + unit test ของกฎ) (3) T-BHI/สถานะ ตกช่องเดียวกันไหม และระบบให้ดีกว่าวิศวกรไหม (**ทิศอันตราย**)
- ข้อเสนอ 10 พ.ย. (ยังไม่ผ่านอาจารย์): ชั้น 2 เทียบ "ระดับแย่สุดรายชิ้นส่วน" · วิศวกรมีตัวเลือก "ตัดสินไม่ได้" · รันกฎด้วยป้ายเฉลยแยกความผิดของ AI กับกฎ · เลือก ~18 ชิ้นก่อนเห็นผลระบบ (จาก BMMS 2567/สำรวจ 13 ต.ค.) · ค่าอ้างอิง = ค่ากลางของ 3 ท่าน / 2 ท่านเห็นต่าง = ค่าที่แย่กว่า · ทิศอันตรายรายงานเป็นจำนวนชิ้น
- ชื่อหน่วยงานในอภิปราย (ทช., การทางพิเศษฯ — ฟังเสียงไม่ชัด, ดอนเมืองโทลเวย์) ยังไม่ตัดสิน · ตาราง mapping T-BHI ↔ เกณฑ์หน่วยงานเป็นงานต่อยอด
