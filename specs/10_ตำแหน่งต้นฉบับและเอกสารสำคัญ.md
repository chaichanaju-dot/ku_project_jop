## 6. เทคนิคอ่านไฟล์ (สภาพแวดล้อม Windows 11)
- PDF ไทยใช้ PyMuPDF (`import pymupdf`) · สระ "ำ" ถอดเพี้ยน " า" · วรรณยุกต์/สระบนอาจหาย · บางไฟล์เป็นภาพสแกน (ถอดเสียง 51 หน้า, comment_30ตค, เปเปอร์ 6 ไฟล์ใน `6_…`) ต้องเรนเดอร์ดูภาพ · ตารางถอดเป็นบรรทัดตรง ตรวจเทียบภาพเมื่อสำคัญ
- .docx ไทยมี ZWSP (U+200B) ตามจุดตัดคำ → ลบก่อนค้น/เทียบ · รอยแก้อยู่ `<w:ins>/<w:del>`, คอมเมนต์ใน `word/comments.xml` · แก้ Track Changes ผ่าน Word COM (PowerShell) UserName = "Claude"
- พิมพ์ Python ภาษาไทยออก stdout: `sys.stdout.reconfigure(encoding='utf-8')` · รัน `python -I` เมื่ออ่านไฟล์ที่ไม่น่าไว้ใจ
- สคริปต์ชั่วคราวเก็บใน scratchpad ของ session ไม่ใช่ใน repo
