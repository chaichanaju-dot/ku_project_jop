# 03 — กฎแปลงความเสียหายที่เห็นในภาพ → ระดับ 0–5 (ตาราง 2.6 และ 3.7.1–3.7.4 ของเล่ม v11)

## 1. กฎทั่วไป
- VLM/SAM ติดป้ายเฉพาะ "สิ่งที่ตาเห็น" **ไม่ติดระดับ** — ระดับมาจากโปรแกรม Python (ทำซ้ำได้) ห้ามให้ LLM/VLM คำนวณ
- ไม่พบความเสียหาย = **ระดับ 5** · **ระดับ 0 ไม่กำหนดจากภาพ**
- ค่าตกพอดีขอบ = ระดับที่แย่กว่า · ช่อง 0.23–0.25 มม. (PC) = ระดับ 2
- พิกเซลที่มาสก์ซ้อนกัน นับ **ระดับที่แย่สุดเพียงระดับเดียว** (3.7.2)
- "หลายจุด/บริเวณกว้าง" = ≥3 จุดต่อชิ้นส่วนในภาพ **หรือ** ≥ร้อยละ 5 ของพื้นที่ชิ้นส่วน (ผู้จัดทำกำหนด ปรับร่วมวิศวกร; ยังรออาจารย์ยืนยัน)
- วัสดุ: **คานหลัก = PC ใช้เกณฑ์ PC · เสา/หัวเสา = RC ใช้เกณฑ์ RC** (ยังต้องยืนยันวัสดุจริง) · พื้นและราวไม่ได้ระบุในเล่ม
- ความลึกกะเทาะ/การเสียหน้าตัดเหล็กตัดสินจากภาพไม่ได้ → ตัวบ่งชี้ทางอ้อม + ค่าความมั่นใจต่ำ

## 2. ตาราง 2.6 รายประเภท (ตามเล่ม v11)
| ประเภท | กฎ |
|---|---|
| **Crack** | วัดความกว้างด้วยสเกลเลเซอร์ แล้วเทียบตาราง 2.4 (ดู 01 §2) · **Rust_Stain ทับรอย → ไม่ดีกว่า 2** · เล่มไม่กำหนดระดับ 1 จากรอยเฉือน/ดัด (ภาพตัดสินไม่ได้) |
| **Crack ที่ตรวจพบแต่วัดไม่ได้** (ไม่มีสเกล หรือ <3 พิกเซล) | **คาน PC = ระดับ 2** (+ ค่าความมั่นใจต่ำ + รายงานตรงๆ ว่าไม่น่าเชื่อถือ) · **ชิ้นส่วน RC = "ตัดสินไม่ได้ ส่งวิศวกรตรวจ"** · **ห้ามให้ระดับ 3 เป็นค่าตั้งต้น** (อาจารย์ท้วงว่าไม่ปลอดภัย; v11 ตัด "ช่วง 1–2" ออกแล้ว) |
| **Spalling** | ไม่เห็นเหล็ก: **4** (จุดเดียว) / **3** (หลายจุด) · เห็นเหล็ก: **2** · เห็นเหล็กหลายจุด: **1** |
| **Exposed_Rebar** | 3 / 2 / 1 (ตาม BMMS; ระดับ 4 ไม่มีแถว) |
| **Honeycomb** | 4–3 เท่านั้น (BMMS ไม่มีระดับ 2, 1) |
| **Efflorescence** | **3 เสมอ** (คราบน้ำ+เกลือรวมเป็นประเภทเดียว แยกจากภาพไม่ได้) |
| **Rust_Stain** | เดี่ยว = 3 · **ทับ Crack → ดัน Crack เป็น 2** · **ติด Exposed_Rebar → ดันเป็น 2** (BMMS ไม่มีเกณฑ์ระดับแยก; ส่วน "ทับเท่าไรถึงดัน" เป็นของผู้จัดทำ) |

## 3. ลำดับการคำนวณต่อชิ้นส่วน (3.7.2–3.7.4)
1. ต่อภาพ i, ชิ้นส่วน e: ระดับของมาสก์แต่ละอัน → พื้นที่ A_{e,i,k}; ระดับ 5 = พื้นที่กรอบชิ้นส่วน − พื้นที่รวมมาสก์
2. จับคู่ความเสียหายกับชิ้นส่วนด้วยกรอบชิ้นส่วนในภาพเดียวกัน (3.5.4): ส่วนของมาสก์ในกรอบชิ้นส่วนใดนับเป็นของชิ้นส่วนนั้น · คร่อมสองกรอบ → แบ่งตามพิกเซลที่ทับ · นอกกรอบทุกกรอบ → "ไม่สังกัดชิ้นส่วน" ไม่เข้าดัชนี (แจ้งตรวจถ้าเกินร้อยละ 50)
3. รวมข้ามภาพ (3.2) → EHI (2.1) → T-BHI (2.2) → สถานะ + กฎบังคับ (ดู 02)
4. รายงานคู่กัน: ระดับแย่สุดของชิ้นส่วน · ค่าความมั่นใจ · รายการชิ้นส่วนที่พบ/ไม่พบ
- PC รอยวัดไม่ได้: นับสัดส่วนระดับ 2 ตามปกติ + ไม่น่าเชื่อถือ · RC รอยตัดสินไม่ได้: คำนวณจากส่วนที่ตัดสินได้ + รายงานส่วนที่ตัดสินไม่ได้

## 4. ข้อเสนอแก้กฎ (Claude 10 พ.ย. — **ยังไม่ผ่านทีม/อาจารย์ ห้ามลงเล่ม**)
จาก `ข้อเสนอกฎตีระดับความเสียหาย_2026-11-10.md` (13 หัวข้อ):
1. เหล็กโผล่ (Exposed_Rebar) = **ระดับ 2 ขึ้นไป** ตัดระดับ 3 (ความเสียหายเดียวกันได้ 2 หรือ 3 ตามว่า AI เจอหลุมกะเทาะด้วยหรือไม่)
2. รอย RC แคบกว่า 3 พิกเซล ให้ระดับ 4 ได้ถ้า 3 × สเกล < 1.6 มม.
3. คูณค่าวัดด้วย (1 + ความคลาดเคลื่อน) ก่อนเทียบเส้นแบ่ง
4. หารความกว้างด้วย cos θ (ผิวเอียง วัดเล็กไป cos θ — 15° 3.4%, 30° 13.4%, 45° 29.3% ผู้จัดทำคำนวณ)
- พบว่าเล่ม v11 ไม่ได้ระบุวัสดุของพื้นและราว (3.7.1 ระบุแค่เสา/หัวเสา RC, คานหลัก PC)
- ข้อ 3.7.1 ย่อหน้าเหตุผลยังเขียน "อาจเป็นระดับ 2 หรือ 1 อยู่แล้ว" (ตั้งใจคงไว้ ถ้าอาจารย์ท้วงค่อยแก้)

## 5. กรณีทดสอบที่ควรมีตอนเขียนโปรแกรม (ยังไม่ได้เขียน — ดู CLAUDE.md กติกา "สคริปต์ทดสอบ")
- รอย PC ตรวจพบแต่ไม่มีสเกล → ระดับ 2 + ความมั่นใจต่ำ (ไม่ใช่ 3)
- รอย RC ตรวจพบแต่ไม่มีสเกล → "ตัดสินไม่ได้ ส่งวิศวกรตรวจ"
- Rust_Stain ทับ Crack ระดับ 3 → Crack = 2 · Rust_Stain ติด Exposed_Rebar → 2
- Efflorescence → 3 เสมอ · Honeycomb ไม่เกิน 3 · ไม่เจออะไร → 5
- มาสก์ซ้อนกัน → นับระดับแย่สุดอันเดียว · ค่าตกขอบ (เช่น 1.6, 3.2, 0.10, 0.23, 0.76 มม.) → ระดับที่แย่กว่า · 0.24 มม. (PC) → ระดับ 2
