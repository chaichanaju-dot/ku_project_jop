# โฟลเดอร์นี้คือ "ความจำ" ทั้งหมดของโปรเจกต์ T-BHI

> ถ้าเปิด Claude Code เซสชันใหม่ (เช่นบนเครื่องอื่น) **ไม่ต้องสั่งอ่านทุกไฟล์ในโฟลเดอร์นี้ตั้งแต่ต้น**
> แค่รู้ว่าไฟล์ไหนมีอะไร แล้วเปิดอ่านเฉพาะไฟล์ที่เกี่ยวกับงาน/คำถามตอนนั้นจริงๆ พอ (ประหยัด token กว่ามาก)

## ไฟล์ที่ควรอ่านก่อนเริ่มงานทุกครั้ง (สั้น เปลืองน้อย)

| ไฟล์ | เนื้อหา |
|---|---|
| **`work_diary.md`** | สถานะล่าสุดตอนนี้ เพิ่งทำอะไรไปทำไม ต้องทำอะไรต่อ — **อ่านไฟล์นี้ก่อนสุดเสมอ** (อัปเดตทุกครั้งที่จบงาน) |
| **`เตรียมตอบอาจารย์.md`** | รวมทุกหัวข้อของโปรเจกต์แบบ Q&A (สถาปัตยกรรม, ที่มาสูตร, วิธีเทรน, dataset, roadmap) — เปิดก่อนคุยกับอาจารย์ |
| **`memory_รวม.md`** | กฎ/พฤติกรรมทั้งหมดที่ตกลงกันไว้ (overfitting, code style, ภาษาที่ใช้อธิบาย, training log, มุมกล้อง, rule of tune) — อ่านถ้าอยากรู้เหตุผลเบื้องหลังกฎต่างๆ |
| **`PROJECT_SUMMARY.md`** | สถาปัตยกรรมที่ตัดสินใจแล้ว (YOLO-seg + RT-DETR + SAM), TODO รวม — อ่านก่อนแตะโค้ด pipeline หลัก |

## ไฟล์ที่อ่านเฉพาะตอนเกี่ยวข้อง

| ไฟล์ | อ่านเมื่อ |
|---|---|
| `rule_of_tune.md` | จะแก้/ลบ/ย้ายไฟล์ในโฟลเดอร์ `01 Literature Review/` หรือ `Bridge/` |
| `สรุป_00_บริบทโครงการ.md` | ถามเรื่องบริบทโครงการแม่ / Tier 1 vs Tier 2 |
| `สรุปสาระสำคัญ เกณฑ์.pdf` | ถามเรื่องสูตร T-BHI / เกณฑ์ตัวเลขความเสียหาย / น้ำหนักชิ้นส่วน |
| `ที่มาความน่าเชื่อถือของสูตร T-BHI.md` | ต้องตอบอาจารย์ว่าสูตร/เกณฑ์มาจากไหน น่าเชื่อถือแค่ไหน (แยกของที่ยืมมาจากมาตรฐาน vs ของที่สังเคราะห์ใหม่เอง พร้อมเลขหน้าอ้างอิงในไฟล์ต้นฉบับ) |
| `การแบ่งชุดข้อมูล_train_valid_test.md` | ถามเรื่องแบ่ง train/valid/test, รอบบิน, เทรนต่อ, จำนวนภาพ |
| `ขั้นตอนเตรียมข้อมูล_labeling.md` | ถามเรื่อง label ด้วย Roboflow/LabelMe, แยก class, augmentation |
| `drone-image-matching-approaches.md` | ถามเรื่องรวมภาพโดรนที่ overlap กัน / กันนับความเสียหายซ้ำข้ามเฟรม (ปัญหายังไม่แก้) |
| `วิธี3-GPS-Gimbal-ละเอียด.md` | ต้องอธิบาย/พิสูจน์วิธี GPS+Gimbal projection ให้อาจารย์ฟังแบบละเอียด (ตัวแปร EXIF ที่ต้องใช้, สูตรคำนวณ+ตัวอย่างเลข, แผน proof ด้วยโมเดล 3D) |
| `0_Reading Guide - คำตอบคำถามนำ.pdf` | ถามเรื่องวรรณกรรม/เปเปอร์ที่อ่านมา |
| `ทำไมเทรนจากตัวเปล่า.md` | ต้องอธิบาย/ปกป้องว่าทำไมไม่เทรนต่อจาก `best.pt` (เหตุผลครบทั้งด้านข้อมูล/โมเดล/พารามิเตอร์ สำหรับใส่รายงานหรือตอบอาจารย์) |
| `training_log.md` | (ยังไม่มีไฟล์นี้ จะถูกสร้างตอนมีผลเทรนจริงรอบแรก) — ประวัติผลเทรนทุกรอบ |
| `บันทึกประจำวัน.md` | ถามว่า "3 วันที่ผ่านมาทำอะไรไปบ้าง" / ต้องการ log งานประจำวันแบบละเอียด |
